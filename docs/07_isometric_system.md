# 🔷 이소메트릭 타일 시스템 현황

## 7.1. 현재 구현된 기능
-   **마름모꼴 타일 렌더링**: 70x35 픽셀 크기의 완벽한 이소메트릭 다이아몬드 형태
-   **3D 깊이감 표현**: 높이차에 따른 자동 측면 생성 및 음영 처리
-   **좌표 변환 시스템**: 정사각형 그리드 ↔ 이소메트릭 마름모 자동 변환
-   **지형별 색상 구분**: 15가지 지형 타입별 고유 색상 지원
-   **높이 기반 시각화**: 높이에 따른 밝기 조정 및 접근 불가 지역 표시

## 7.2. 기술적 세부사항
-   **타일 크기**: 70x35 픽셀 (이소메트릭 2:1 비율)
-   **좌표 변환 공식**:
    ```
    iso_x = (grid_x - grid_y) * 35
    iso_y = (grid_x + grid_y) * 17.5
    ```
-   **높이 표현**: 각 높이 레벨당 15픽셀 Y 오프셋
-   **측면 렌더링**: 인접 타일과의 높이차 계산하여 자동 생성

## 7.3. 향후 개선 계획
### 7.3.1. 스프라이트 기반 렌더링 (우선순위: 높음)
현재 Polygon2D 단색 표현을 텍스처 기반으로 업그레이드:
-   **지형별 픽셀 아트 스프라이트 제작**:
    -   평지: 잔디 텍스처 (64x32 PNG)
    -   산: 바위 텍스처 + 눈 덮인 봉우리
    -   숲: 나무 실루엣 + 잎사귀 디테일
    -   늪: 물기 있는 진흙 + 기포 효과
    -   사막: 모래 언덕 + 선인장
    -   화산: 용암 흐름 + 연기 파티클
    -   강: 물 흐름 애니메이션 + 반사 효과
-   **높이별 변형 스프라이트**: 같은 지형도 높이에 따라 다른 변형 제공
-   **계절별/날씨별 변형**: 눈 덮인 버전, 비 젖은 버전 등

### 7.3.2. 애니메이션 효과 (우선순위: 중간)
-   **지형 애니메이션**:
    -   강: 물결 효과
    -   화산: 용암 글로우 + 파티클
    -   불타는 땅: 화염 효과
    -   얼음: 반짝임 효과
-   **환경 파티클**:
    -   눈/비 날씨: 파티클 시스템
    -   안개: 반투명 오버레이
    -   모래폭풍: 움직이는 모래 텍스처

### 7.3.3. 고급 시각 효과 (우선순위: 낮음)
-   **동적 조명**: 화염, 마법 등의 광원 효과
-   **그림자 시스템**: 높이에 따른 실시간 그림자
-   **시차 스크롤링**: 배경 레이어 추가

## 7.4. 현재 지형 표현력 평가
**✅ 충분히 표현 가능한 요소들:**
-   기본 지형 구분 (평지, 산, 숲, 물 등)
-   높이 차이 및 고저차 표현
-   지형 간 경계 및 전환
-   시각적 깊이감 및 3D 효과
-   마우스 인터랙션 (호버, 클릭)

**🔄 개선이 필요한 요소들:**
-   지형 디테일 (현재는 단색, 향후 텍스처 필요)
-   특수 효과 (화염, 물 흐름 등의 애니메이션)
-   날씨/시간대 변화 표현

**결론**: 현재 시스템은 이소메트릭 SRPG의 핵심 요구사항을 모두 만족하며, 스프라이트 교체만으로도 상업적 품질의 비주얼을 달성할 수 있습니다.
