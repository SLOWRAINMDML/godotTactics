## 🚀 프로젝트 개요

이 프로젝트는 **Godot 4.4**를 기반으로 한 이소메트릭 턴제 전략 시뮬레이션 RPG입니다.

### 핵심 특징
- 🎯 **깊이 있는 전략성**: 지형, 높이, 속성, 환경을 모두 고려한 전술 전투
- 🎨 **이소메트릭 2D 픽셀 아트**: 아름다운 시각적 표현과 3D 깊이감
- 👥 **개인별 성장 시스템**: 각 캐릭터의 고유한 성장률과 클래스 특화
- 🔧 **통합 에디터 시스템**: 맵 에디터와 시나리오 에디터로 콘텐츠 제작 지원
- 🤖 **적응형 AI**: 플레이어 패턴을 학습하는 개인화된 AI 시스템

### 개발 워크플로우
```
랜덤 맵 생성 → 마음에 드는 맵 저장 → 세밀한 편집 → 시나리오 연결 → AI 학습
```

### 기술 스택
- **엔진**: Godot 4.4
- **언어**: GDScript
- **그래픽**: 2D 이소메트릭 픽셀 아트
- **데이터**: JSON 기반 구조화된 데이터 관리
- **AI**: 로컬 서버 연동 패턴 분석 (별도 구현 예정)
