# 🏯 조선-일본 역사 기반 클래스 시스템

## 📋 문서 개요

이 문서는 조선시대와 일본의 역사적 무관 체계, 무녀, 민간 무력 집단을 바탕으로 한 게임 클래스 시스템 설계 아이디어를 정리합니다. 각 클래스는 역사적 사실을 바탕으로 하되, 게임 밸런스와 재미를 고려하여 재해석되었습니다.

## 🇰🇷 조선시대 삼수병 체계 기반 클래스

### 핵심 전투 클래스 - 삼수병 (三手兵)

임진왜란 이후 조선의 군사 체계는 훈련도감을 중심으로 한 **삼수병(三手兵)** 체제로 개편되었습니다. 포수(砲手), 살수(殺手), 궁수(弓手)가 유기적으로 협력하여 전투를 수행하는 체계입니다.

#### 🔫 포수 (砲手, Musketeer)
- **역사적 배경**: 훈련도감의 핵심 병과, 조총을 사용한 원거리 화력 제공
- **게임 특성**: 긴 사거리와 파괴력, 재장전 시간 존재, 근접전 취약
- **주요 능력치**: 기술(DEX), 힘(STR)
- **사용 무기**: 조총, 화승총
- **전직 조건**: Lv.3, DEX 15+ + 화기 훈련 완료

**주요 스킬 (15개)**:
- **공격**: 정조준, 삼단 철환, 철갑탄, 소이탄, 별화포(궁극기)
- **전술**: 연막탄, 이동 사격, 화약 다지기, 속사 장전, 죽음의 시선
- **협력**: 일제 사격, 삼수병 연계, 위협 포성
- **특수**: 개머리판 강타, 약점 포착, 매의 눈

#### ⚔️ 살수 (殺手, Slayer/Infantry)
- **역사적 배경**: 검, 창, 당파 등 다양한 근접 무기를 사용하는 백병전 전문가
- **게임 특성**: 튼튼한 방어력과 뛰어난 근접 제압 능력, 최전선 담당
- **주요 능력치**: 힘(STR), 체력(VIT)
- **사용 무기**: 환도, 장창, 당파, 팽배(방패)
- **전직 조건**: Lv.3, STR 15+ + 백병전 훈련 완료

**주요 스킬 (16개)**:
- **공격**: 일자 창격, 회전 베기, 돌격, 걷어차기, 낭선비검(궁극기)
- **방어**: 팽배 방어, 받아치기, 철벽 방진, 검과 방패
- **버프**: 함성, 백전노장, 불굴의 의지
- **특수**: 출혈 유발, 당파술, 예리한 칼날, 도발

#### 🏹 궁수 (弓手, Archer)
- **역사적 배경**: 전통적인 강력함을 자랑하는 원거리 병과
- **게임 특성**: 포수보다 빠른 연사 속도, 다양한 특수 화살로 전장 교란
- **주요 능력치**: 민첩(AGI), 기술(DEX)
- **사용 무기**: 각궁, 편전, 소형 화기
- **전직 조건**: Lv.3, DEX 15+ + 궁술 훈련 완료

**주요 스킬 (16개)**:
- **공격**: 속사, 편전, 불화살, 독화살, 침묵의 화살, 신기전(궁극기)
- **전술**: 곡사, 올가미 화살, 발목 쏘기, 화살비
- **버프**: 매의 눈, 바람 읽기, 효시, 활줄 강화
- **특수**: 은신, 화살 제작

### 🔗 삼수병 연계 시스템

#### 삼수병 조합 보너스
조선의 삼수병이 함께 있을 때 발동되는 특별한 보너스:

| 조합 | 거리 | 효과 |
|------|------|------|
| **포수 + 살수** | 2칸 내 | 포수 재장전 시간 -1, 살수 방어력 +10% |
| **포수 + 궁수** | 2칸 내 | 원거리 공격 명중률 +15%, 사거리 +1 |
| **살수 + 궁수** | 2칸 내 | 궁수 근접전 회피율 +20%, 살수 이동 후 공격 가능 |
| **삼수병 완편** | 3칸 내 | 모든 능력치 +10%, 특수 합동 공격 "삼수일체" 사용 가능 |

#### 특수 합동 공격: 삼수일체 (Three Arms Unity)
- **조건**: 포수, 살수, 궁수가 모두 3칸 내에 위치
- **효과**: 
  1. 살수가 적진에 돌입하여 방어선 붕괴
  2. 궁수가 광역 화살비로 적들을 분산
  3. 포수가 결정타 포격으로 마무리
- **피해**: 지정된 5x5 범위에 막대한 복합 피해
- **재사용**: 전투당 1회

### 특수 정예 클래스

#### 🐅 착호갑사 (捉虎甲士, Tiger Hunter)
- **역사적 배경**: 왕명으로 호랑이를 사냥하던 특수 정예 부대
- **게임 특성**: 뛰어난 생존 기술과 추적 능력, 강력한 한 방, 암살자 겸 정찰병
- **주요 능력치**: 민첩(AGI), 힘(STR)
- **사용 무기**: 장창, 쇠뇌, 각종 덫
- **전직 조건**: 삼수병 Lv.8+ + 특별 임무 수행

**주요 스킬 (16개)**:
- **공격**: 맹호격, 쇠뇌 사격, 급소 가격, 산군의 포효(궁극기)
- **정찰**: 흔적 추적, 은밀 기동, 영점 포착, 피 냄새 맡기
- **덫**: 함정 설치, 연막 은신
- **생존**: 독 바르기, 야생 생존술, 지형 극복, 길리슈트, 일격필살, 사냥개 호출

#### 🐎 기병 (騎兵, Cavalry)
- **역사적 배경**: 말을 타고 전장을 누비는 기동 부대
- **게임 특성**: 압도적인 이동력으로 측면 공격, 후방 교란, 평지에서 위력 극대화
- **주요 능력치**: 민첩(AGI), 힘(STR)
- **사용 무기**: 기창, 마상편곤, 활
- **전직 조건**: 착호갑사 Lv.5+ + 기마술 습득

**주요 스킬 (16개)**:
- **기동**: 기마 돌격, 치고 빠지기, 진형 파괴, 질풍, 철기병 돌파(궁극기)
- **전투**: 기사(기마 사격), 마상편곤, 짓밟기, 위압적인 존재감
- **지원**: 아군 구원, 흙먼지 일으키기, 선봉 정찰, 군기수
- **말 관련**: 예비마, 험지 주파, 채찍질

#### ⚓ 수군 (水軍, Naval Marine)
- **역사적 배경**: 판옥선을 지휘하며 해상전을 책임지는 병과
- **게임 특성**: 강력한 함포 사격과 해상 기동력, 육지에서는 전투력 감소하지만 지원 가능
- **주요 능력치**: 기술(DEX), 정신(SPI)
- **사용 무기**: 활, 도검, 함포(천자총통 등)
- **전직 조건**: 기병 Lv.5+ + 해상 경험

**주요 스킬 (16개)**:
- **함포**: 천자총통 포격, 쇠사슬탄, 조란탄 발사, 해안 포격 지원
- **해상 전술**: 충파, 등선 명령, 학익진(궁극기)
- **해상 지원**: 순풍 기원, 조류 파악, 진격의 북소리, 응급 수리, 망루 감시
- **백병전**: 작살 투척, 밀어 떨어뜨리기
- **특수**: 뱃노래, 견고한 판옥선

### 전직 체계 및 성장 경로

#### 기본 전직 경로
```
기본병 → 포수/살수/궁수 (삼수병)
    ↓
착호갑사 (특수 정예)
    ↓  
기병 (기동 부대)
    ↓
수군 (해상 전문)
```

**대장군 (大將軍)**

- **전직 조건**: 수군 Lv.10+ + 대규모 전투 승리 경험
- **고유 스킬**: 『군령일하』(전체 아군 1턴 추가 행동), 『위풍당당』(적군 전체 공격력 -20%)

**절도사 (節度使)**
- **역사적 배경**: 지방 군사력 총괄, 도 단위 방어 책임
- **전직 조건**: 수군 Lv.8+ + 성공적인 방어전 경험
- **고유 스킬**: 『견고방어』(아군 전체 방어력 +50%), 『지형장악』(지형 효과 2배)

### 일본 민간 무력

- **게임 특성**:
  - 도시 치안 관리
  - 포박 및 제압 기술
  - 민간인 보호 특화
- **전직 조건**: 치안 유지 경험 + 정의감 80+
- **고유 스킬**:
  - 『포박술』: 적을 무력화하여 포박

  - 십수와 포박 도구 활용
  - 범죄자 체포 전문
- **전직 조건**: 동심 Lv.5+ + 수사 능력
- **고유 스킬**:
  - 『수사술』: 적의 약점 및 정보 파악
  - 『십수던지기』: 적의 이동 봉쇄

  - 기본적인 치안 능력
  - 민간인과의 협력
  - 정보 수집 네트워크
- **전직 조건**: 기본 치안 클래스
- **고유 스킬**:
  - 『민간협력』: 민간인으로부터 정보 획득
  - 『순찰근무』: 지역 내 모든 변화 감지

## 🎯 클래스 체계 및 전직 트리

### 조선 무관 전직 트리
```
백호 → 천호 → 만호 → 첨절제사 → 절도사 → 대장군
  ↓
특수 부대 (훈련도감, 어영청, 내금위)
  ↓
민간 무력 (의병장, 사냥꾼)
```

### 일본 무사 전직 트리
```
고케닌 → 하타모토 → 다이묘
  ↓
특수 집단 (닌자, 야마부시, 소헤이)
  ↓
민간 치안 (도신 → 요리키 → 마치부교)
```

### 종교/무녀 전직 트리
```
기도사 → 미코 → 이타코
```

## 📊 클래스별 능력치 특성

### 능력치 기준
- **STR**: 물리 공격력
- **DEF**: 물리 방어력  
- **AGI**: 민첩성/속도
- **DEX**: 정확도/기술
- **INT**: 지능/전술
- **RES**: 마법 저항력
- **CHA**: 카리스마/지휘력
- **SPI**: 정신력/영력

### 클래스별 주요 능력치
| 클래스 | 주요 능력치 | 부 능력치 | 특화 분야 |
|--------|-------------|-----------|-----------|
| 대장군 | CHA, INT | STR, DEF | 대규모 지휘 |
| 다이묘 | CHA, INT | STR, DEF | 영지 관리 |
| 닌자 | AGI, DEX | STR, INT | 은밀 작전 |
| 미코 | SPI, INT | RES, CHA | 정화/치유 |
| 의병장 | CHA, STR | DEF, INT | 민중 동원 |
| 소헤이 | STR, SPI | DEF, INT | 법술 무예 |
