# 👹 요괴 기반 적 시스템

## 📋 문서 개요

이 문서는 일본 전통 요괴들을 기반으로 구축된 게임의 적 시스템에 대한 종합 가이드입니다. `enemy.md`에 기록된 18세기 일본의 요괴 도감 『화도백귀야행』을 기반으로 하여, 각 요괴들의 원래 특성을 게임 시스템에 맞게 재해석하고 구현했습니다.

## 🎯 시스템 개요

### 핵심 설계 철학
- **전통적 진정성**: 실제 일본 민속학적 자료 기반의 요괴 특성 반영
- **전략적 다양성**: 각 요괴별 고유한 전투 패턴과 지형 특화
- **문화적 몰입**: 요괴들의 원래 설화와 능력을 게임 내에서 체험

### 파일 구조
```
scripts/
├── EnemyData.gd          # 기본 적 데이터 구조 및 기본 요괴들 (8종)
├── EnemyDataExtended.gd  # 추가 요괴들 및 확장 기능 (10종)
├── EnemySkills.gd        # 요괴들의 스킬 정의 (20+ 스킬)
└── EnemyManager.gd       # 적 관리 및 사용 예제
```

## 🎭 요괴 분류 체계

### 정령계 (YOKAI_SPIRIT)
자연과 일체화된 정령들로, 환경과의 조화를 통해 힘을 발휘합니다.

**주요 특징**:
- 지형 특화 능력이 뛰어남
- 자연 속성 마법에 강함
- 환경 조작 능력 보유

**포함 요괴**: 목매, 야마비코, 야마와라와, 야마우바

### 동물계 (YOKAI_ANIMAL)
동물이 오랜 세월을 거쳐 변화한 요괴들로, 원래 동물의 특성을 강화한 능력을 가집니다.

**주요 특징**:
- 높은 민첩성과 기동력
- 둔갑술과 변신 능력
- 특수한 공격 패턴

**포함 요괴**: 네코마타, 갓파, 다누키, 가와우소, 조로구모

### 쓰쿠모가미 (YOKAI_OBJECT)
오래된 물건에 깃든 영혼들로, 원래 물건의 기능을 초월한 능력을 보입니다.

**주요 특징**:
- 특수한 보조 및 지원 능력
- 매혹과 정신 조작 스킬
- 문화적 배경이 깊은 능력들

**포함 요괴**: 고토후루누시, 비와보쿠보쿠, 고소데노테, 지리즈카카이오

### 자연계 (YOKAI_NATURE)
자연 현상을 조작하고 다루는 요괴들입니다.

**주요 특징**:
- 날씨와 환경 조작
- 원거리 공격 특화
- 광역 효과 스킬

**포함 요괴**: 텐구, 기쓰네비, 쓰루베비

### 언데드계 (YOKAI_UNDEAD)
죽은 자의 원념이 형상화된 존재들입니다.

**주요 특징**:
- 물리 공격에 저항
- 어둠 속성 특화
- 지속 효과 능력

**포함 요괴**: 소겐비

### 악마계 (YOKAI_DEMON)
지옥에서 온 강력한 악마들입니다.

**주요 특징**:
- 압도적인 물리 능력
- 화염 속성 특화
- 보스급 전투력

**포함 요괴**: 오니

## ⚔️ 특수 시스템

### 속성 상호작용 시스템
**화염 + 바람 = 확산**:
- 기쓰네비의 화염 공격 + 텐구의 바람 → 화염 범위 2배 확장

**번개 + 물 = 체인 라이트닝**:
- 갓파가 물 지형 생성 → 번개 속성 공격 시 광역 피해

**독 + 바람 = 독성 확산**:
- 조로구모의 독 공격 + 바람 → 독 효과가 주변으로 확산

## 💡 전략적 활용 팁

### 1. 지형 우선 분석
전투 시작 전 맵의 지형을 분석하여 어떤 요괴들이 등장할지 예측하고 대응 전략을 수립하세요.

### 2. 속성 상성 활용
각 요괴의 약점 속성을 파악하여 해당 속성의 캐릭터를 우선 배치하세요.

### 3. 연계 공격 차단
요괴들 간의 상호작용과 연계 공격을 방해하기 위해 핵심 요괴을 우선 제거하세요.

### 4. 환경 활용
지형 변화 스킬을 사용하여 요괴들의 지형 특화 능력을 무력화시키세요.

### 5. 특수 이벤트 대비
특정 요괴 조합이 등장하면 특수 이벤트가 발생할 수 있으므로 미리 대비하세요.
