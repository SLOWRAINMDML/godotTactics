# 🎯 게임 기획 및 컨셉

## 1.1. 게임 개요
-   **장르**: 이소메트릭 턴제 전략 시뮬레이션 RPG (SRPG)
-   **그래픽 스타일**: 2D 픽셀 아트 (이소메트릭 뷰)
-   **핵심 컨셉**: 깊이 있는 전략성을 제공하는 SRPG. 플레이어는 지형의 높낮이, 땅의 상태, 캐릭터의 성장 방향과 클래스, 외부 전황까지 고려하여 전투를 승리로 이끌어야 합니다.

## 1.2. 기획 의도
단순한 턴제 전투를 넘어, 매 순간 전략적인 선택의 깊이를 더하는 것을 목표로 합니다.
-   **지형의 전략화**: 높이와 지형 종류가 단순한 이동 페널티를 넘어, 공격과 방어의 핵심 요소로 작용합니다.
-   **동적인 전장**: 전투 중에도 외부 요인이 전황에 영향을 미쳐, 플레이어는 고정된 전략이 아닌 유연한 대응을 해야 합니다.
-   **성장의 자유도**: 캐릭터의 개인별 성장률을 파악하고 최적의 클래스로 성장시키는 육성의 재미를 제공합니다.
