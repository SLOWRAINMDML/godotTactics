# 🔥 핵심 전투 시스템

## 2.1. 턴제 전투 시스템
-   **행동 순서**: 
    -   **팀 단위 턴제**: 아군 팀 전체 → 적군 팀 전체 순서로 번갈아 진행
    -   **선공권 결정**: 누가 먼저 시작할지는 스토리 상황에 따라 결정됩니다
        -   기습 공격 시나리오: 기습하는 쪽이 선공
        -   정면 대결: 양군 대표의 `DEX` 비교 또는 스토리 설정에 따라 결정
        -   매복/방어: 방어측이 선공하거나 공격측이 선공하는 등 상황별 차별화
    -   **팀 내 행동 순서**: 각 팀의 턴에서는 플레이어가 원하는 캐릭터를 자유롭게 선택하여 행동 순서를 결정
-   **액션 포인트 시스템**: 
    -   **기본 액션 포인트**: 모든 캐릭터는 기본적으로 턴마다 2개의 액션 포인트를 갖습니다.
    -   **DEX 보너스**: `DEX` 스탯이 높을수록 추가 액션 포인트가 부여됩니다. (예: DEX 15+ = +1 액션, DEX 20+ = +2 액션)
    -   **액션 소비**: 이동 1회 = 1 액션, 공격/스킬 1회 = 1 액션
    -   **행동 예시**: DEX 보너스 +2를 받은 캐릭터(총 4 액션)는 "이동 → 공격 → 공격 → 이동" 또는 "이동 → 스킬 → 이동 → 공격" 등의 연속 행동이 가능합니다.
-   **액션 포인트 변동 요소**:
    -   **지형 페널티**: 늪지(-1 액션), 깊은 눈(-1 액션) 등으로 행동력 감소
    -   **날씨 효과**: 폭우(-1 액션), 강풍(원거리 공격 -1 액션) 등의 환경적 제약
    -   **상태 이상**: 마비(-2 액션), 둔화(-1 액션), 피로(-1 액션) 등으로 행동력 제한

## 2.2. 이소메트릭 지형 및 높이 시스템
-   **높낮이 효과**:
    -   **고지대**: 높은 곳에 위치한 유닛은 낮은 곳의 적을 공격할 때 명중률과 데미지 보너스를 얻습니다.
    -   **사거리 제한**: 무기 사거리는 수직 높이까지 계산에 포함되어, 너무 높은 곳에 있는 적은 공격할 수 없습니다.
-   **시야 시스템**:
    -   **고지대 시야 보너스**: 높은 곳에 위치한 유닛은 더 넓은 범위의 적을 발견할 수 있습니다.
    -   **시야 범위**: 기본 시야 + (현재 높이 - 주변 평균 높이) 만큼 시야가 확장됩니다.
    -   **은신 및 차폐**: 숲, 건물 등의 장애물 뒤에 숨은 적은 시야에서 제외되거나 발견 확률이 감소합니다.
-   **밀치기 공격 시스템**:
    -   **밀치기 속성**: 일부 공격(돌진, 방패 밀기 등)은 대상을 1~2칸 밀어낼 수 있습니다.
    -   **낙하 데미지**: 밀려난 대상이 높은 곳에서 낮은 곳으로 떨어질 경우 낙차에 비례한 추가 데미지를 받습니다.
        -   낙차 1칸 = 경미한 데미지, 낙차 2칸+ = 심각한 데미지
        -   극심한 낙차(3칸+)의 경우 즉사 위험도 존재
    -   **전략적 활용**: 절벽 근처에서의 위치 선점이 중요한 전략 요소가 됩니다.
-   **지형 종류 및 효과**:
    -   **Plain(평지)**: 기본 지형, 특별한 효과 없음
    -   **Mountain(산)**: 이동 비용 +2, 고지대 보너스(공격력/명중률 +20%), 시야 범위 +2
    -   **Forest(숲)**: 이동 비용 +1, 은신 효과, 원거리 공격 회피율 +15%, 화염 속성 피해 +50%
    -   **Swamp(늪)**: 이동 비용 +3, 이동력 -1, 독 상태이상 확률 10%, 번개 속성 피해 +30%
    -   **Desert(사막)**: 이동 비용 +1, 갈증 상태(턴마다 MP -2), 화염 속성 저항 +20%, 얼음 속성 피해 +40%
    -   **Volcano(화산지대)**: 이동 비용 +2, 턴마다 화염 데미지, 화염 속성 피해 +100%, 화염 속성 저항 -50%
    -   **River(강)**: 이동 비용 +2, 젖은 상태(화염 저항 +30%, 번개 피해 +50%), 수영 불가 시 익사 위험
        - 번개 속성 공격 시 주변 1칸 범위 광역 피해 발생
    -   **Rocky(바위지대)**: 이동 비용 +1, 투사 무기 명중률 +10%, 낙석 위험 지역
    -   **Ice(빙하지대)**: 이동 비용 +1, 미끄러짐 효과(이동 후 추가 1칸 미끄러짐), 얼음 속성 저항 +50%, 화염 속성 피해 +30%
    -   **Cave(동굴)**: 이동 비용 +1, 시야 범위 -2, 음향 증폭(소음 기반 스킬 효과 +50%)
    -   **Bridge(다리)**: 이동 비용 0, 좁은 통로로 대형 유닛 통과 불가, 파괴 가능 구조물
    -   **Lava(용암)**: 진입 불가, 화염 속성 광역 데미지 방사(인접 칸에 화염 피해)
    -   **Quicksand(유사)**: 이동 비용 +4, 매 턴 침몰 진행(3턴 후 익사), 탈출 시 STR 체크 필요
    -   **Thorn(가시덤불)**: 이동 비용 +2, 진입 시 출혈 상태, 화염 속성으로 제거 가능
    -   **Mud(진흙)**: 이동 비용 +2, 기동성 -1, 번개 속성 전도율 증가(주변 2칸 광역 피해)

## 2.3. 환경 상호작용

### 2.3.1. 날씨 시스템
-   **날씨 효과**:
    -   **맑음**: 기본 상태, 특별한 효과 없음
    -   **비**: 화염 속성 -30%, 번개 속성 +20%, 시야 범위 -1, 모든 유닛 젖은 상태
    -   **폭우**: 화염 속성 -50%, 번개 속성 +50%, 시야 범위 -2, 강 범람으로 일부 평지가 강으로 변환
    -   **눈**: 이동력 -1, 얼음 속성 +30%, 화염 속성 +20%, 발자국 추적 가능
    -   **블리자드**: 이동력 -2, 시야 범위 -3, 얼음 속성 +50%, 매 턴 동상 데미지
    -   **폭풍**: 원거리 공격 명중률 -20%, 비행 불가, 번개 속성 광역 피해 확률
    -   **사막 모래폭풍**: 시야 범위 -2, 화염 속성 +10%, 매 턴 질식 데미지, 기계 유닛 고장 확률
    -   **화산재**: 시야 범위 -1, 화염 속성 +20%, 매 턴 중독 데미지, 비행 고도 제한
    -   **안개**: 시야 범위 -3, 은신 효과 증가, 원거리 공격 명중률 -30%
    -   **오로라**: 마법 공격력 +20%, MP 회복률 +1, 환상 마법 저항 -20%
    -   **혹한**: 이동력 -1, 매 턴 HP -2, 화염 속성 회복 효과, 액체 지형 얼음화
    -   **열파**: 사막/화산 지형 피해 2배, 갈증 상태 확률, 얼음 지형 용해

### 2.3.2. 지형-속성 상호작용
-   지형의 상태와 스킬의 속성이 결합하여 추가 효과를 발생시킵니다:
    -   **화염 속성 상호작용**:
        - 숲 + 화염 = 불타는 숲 (지속 화염 데미지, 연쇄 확산)
        - 가시덤불 + 화염 = 가시덤불 제거 (지형이 평지로 변화)
        - 얼음 + 화염 = 물웅덩이 생성 (임시 강 지형 효과)
        - 진흙 + 화염 = 건조한 땅 (이동 페널티 제거)
    -   **번개 속성 상호작용**:
        - 강/진흙 + 번개 = 주변 2칸 광역 감전 (체인 라이트닝)
        - 금속 장비 착용 시 번개 피해 +100%
        - 비 날씨 + 번개 = 전체 맵 번개 확률 증가
    -   **얼음 속성 상호작용**:
        - 강 + 얼음 = 임시 얼음 다리 생성 (3턴 후 해빙)
        - 진흙 + 얼음 = 빙판 (미끄러짐 거리 2배)
        - 화산 + 얼음 = 증기 폭발 (광역 데미지 + 시야 차단)
    -   **바람 속성 상호작용**:
        - 화염 + 바람 = 화염 확산 (인접 칸으로 번짐)
        - 독성 가스 + 바람 = 독성 확산
        - 모래폭풍 + 바람 = 모래폭풍 강화 (시야 완전 차단)
    -   **대지 속성 상호작용**:
        - 평지 + 대지 = 언덕 생성 (고지대 효과)
        - 동굴 + 대지 = 낙석 (광역 물리 데미지)
        - 절벽 + 대지 = 지진 (주변 유닛 넘어짐)
    -   **독 속성 상호작용**:
        - 늪지 + 독 = 독성 늪 (독 데미지 2배, 독 확산)
        - 강 + 독 = 독성 강물 (하류로 독 확산, 정화 시간 필요)
        - 바람 + 독 = 독성 바람 (광역 독 확산, 이동 경로 따라 중독)
        - 동굴 + 독 = 독가스 농축 (밀폐 공간에서 독 효과 3배)

### 2.3.3. 특수 환경 지형
-   **추가 특수 지형**:
    -   **Altar(제단)**: 신성 속성 마법 위력 +50%, 언데드 유닛에게 지속 피해, MP 회복 +1
    -   **Graveyard(묘지)**: 언데드 소환 확률, 신성 속성 저항 +30%, 어둠 속성 강화 +20%
    -   **Crystal(수정지대)**: 마법 데미지 반사 30%, 마나 회복 +2, 물리 공격 시 수정 파편 피해
    -   **Teleporter(순간이동진)**: 맵 내 다른 순간이동진으로 즉시 이동, 1턴 쿨타임
    -   **Poison_Gas(독가스)**: 매 턴 독 데미지, 시야 범위 -1, 바람으로 확산/제거 가능
    -   **Web(거미줄)**: 이동 비용 +3, 탈출 시 STR 체크, 화염으로 제거 가능
    -   **Tar_Pit(타르 웅덩이)**: 이동 비용 +4, 화염 취약 +200%, 점착 상태(3턴간 이동력 -2)
    -   **Blessed_Ground(축복받은 땅)**: 아군 유닛 모든 능력치 +10%, 언데드/악마 진입 불가
    -   **Cursed_Ground(저주받은 땅)**: 매 턴 랜덤 디버프, 언데드 유닛 강화 +30%
    -   **Magnetic_Field(자기장)**: 금속 장비 착용 유닛 이동 제한, 번개 속성 집중

### 2.3.4. 상태 이상 시스템
-   **기본 상태 이상**:
    -   **중독(Poison)**: 매 턴 HP 감소 (3-5턴 지속)
        - **약한 중독**: 매 턴 HP -3, 3턴 지속
        - **일반 중독**: 매 턴 HP -5, 4턴 지속  
        - **강한 중독**: 매 턴 HP -8, 5턴 지속
        - **치명적 중독**: 매 턴 HP -12, 5턴 지속 + 치료 효과 -50%
        - **독 데미지 공식**: `독 데미지 = 기본 독 데미지 × (1 - 독 저항률) × (1 + 독 취약성)`
        - **독 저항 계산**: `독 저항률 = (RES × 0.1) + 장비 독 저항 + 버프 효과`
    -   **화상(Burn)**: 매 턴 화염 데미지 (2-4턴 지속)
    -   **동상(Frostbite)**: 이동력 -1, 행동력 -1 (2-3턴 지속)
    -   **마비(Paralysis)**: 행동 불가 (1-2턴 지속)
    -   **수면(Sleep)**: 행동 불가, 공격받으면 즉시 해제
    -   **매혹(Charm)**: 1턴간 적으로 전환되어 아군 공격
    -   **침묵(Silence)**: 마법/스킬 사용 불가 (2-3턴 지속)
    -   **실명(Blind)**: 명중률 -50%, 시야 범위 -3 (2-4턴 지속)
    -   **출혈(Bleeding)**: 이동 시 추가 HP 감소 (3-5턴 지속)
-   **환경 상태 이상**:
    -   **젖은 상태(Wet)**: 화염 저항 +30%, 번개 피해 +50% (날씨/지형으로 발생)
    -   **갈증(Thirst)**: 매 턴 MP -2, 사막 지형에서 발생
    -   **질식(Suffocation)**: 매 턴 HP -3, 독가스/모래폭풍에서 발생
    -   **점착(Sticky)**: 이동력 -2, 타르/거미줄에서 발생 (3턴 지속)
    -   **발열(Fever)**: INT -20%, 화산/열파에서 발생 (5턴 지속)

-   **체력/마나 상태 효과**:
    -   **건강(Healthy)**: HP 80% 이상, 모든 행동 +10% 효율
    -   **부상(Injured)**: HP 50% 이하, 이동력 -1, 명중률 -10%
    -   **중상(Heavily Injured)**: HP 25% 이하, 모든 스탯 -20%, 절망 스킬 사용 가능
    -   **빈사(Near Death)**: HP 10% 이하, 행동력 -1, 크리티컬 확률 +25% (최후의 발악)
    -   **마나 충만(Mana Full)**: MP 90% 이상, 마법 스킬 위력 +20%, 쿨타임 -1턴
    -   **마나 부족(Low Mana)**: MP 30% 이하, 마법 스킬 위력 -15%, 실패 확률 10%
    -   **마나 고갈(Mana Depleted)**: MP 10% 이하, 마법 스킬 사용 불가, INT -30%
