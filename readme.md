## 1. 게임 기획 및 컨셉

### 1.1. 게임 개요
-   **장르**: 이소메트릭 턴제 전략 시뮬레이션 RPG (SRPG)
-   **그래픽 스타일**: 2D 픽셀 아트 (이소메트릭 뷰)
-   **핵심 컨셉**: 깊이 있는 전략성을 제공하는 SRPG. 플레이어는 지형의 높낮이, 땅의 상태, 캐릭터의 성장 방향과 클래스, 외부 전황까지 고려하여 전투를 승리로 이끌어야 합니다.

### 1.2. 기획 의도
단순한 턴제 전투를 넘어, 매 순간 전략적인 선택의 깊이를 더하는 것을 목표로 합니다.
-   **지형의 전략화**: 높이와 지형 종류가 단순한 이동 페널티를 넘어, 공격과 방어의 핵심 요소로 작용합니다.
-   **동적인 전장**: 전투 중에도 외부 요인이 전황에 영향을 미쳐, 플레이어는 고정된 전략이 아닌 유연한 대응을 해야 합니다.
-   **성장의 자유도**: 캐릭터의 개인별 성장률을 파악하고 최적의 클래스로 성장시키는 육성의 재미를 제공합니다.

## 2. 핵심 게임플레이 시스템

### 2.1. 턴제 전투 시스템
-   **행동 순서**: 
    -   **팀 단위 턴제**: 아군 팀 전체 → 적군 팀 전체 순서로 번갈아 진행
    -   **선공권 결정**: 누가 먼저 시작할지는 스토리 상황에 따라 결정됩니다
        -   기습 공격 시나리오: 기습하는 쪽이 선공
        -   정면 대결: 양군 대표의 `DEX` 비교 또는 스토리 설정에 따라 결정
        -   매복/방어: 방어측이 선공하거나 공격측이 선공하는 등 상황별 차별화
    -   **팀 내 행동 순서**: 각 팀의 턴에서는 플레이어가 원하는 캐릭터를 자유롭게 선택하여 행동 순서를 결정
-   **액션 포인트 시스템**: 
    -   **기본 액션 포인트**: 모든 캐릭터는 기본적으로 턴마다 2개의 액션 포인트를 갖습니다.
    -   **DEX 보너스**: `DEX` 스탯이 높을수록 추가 액션 포인트가 부여됩니다. (예: DEX 15+ = +1 액션, DEX 20+ = +2 액션)
    -   **액션 소비**: 이동 1회 = 1 액션, 공격/스킬 1회 = 1 액션
    -   **행동 예시**: DEX 보너스 +2를 받은 캐릭터(총 4 액션)는 "이동 → 공격 → 공격 → 이동" 또는 "이동 → 스킬 → 이동 → 공격" 등의 연속 행동이 가능합니다.
-   **액션 포인트 변동 요소**:
    -   **지형 페널티**: 늪지(-1 액션), 깊은 눈(-1 액션) 등으로 행동력 감소
    -   **날씨 효과**: 폭우(-1 액션), 강풍(원거리 공격 -1 액션) 등의 환경적 제약
    -   **상태 이상**: 마비(-2 액션), 둔화(-1 액션), 피로(-1 액션) 등으로 행동력 제한

### 2.2. 이소메트릭 지형 및 높이 시스템
-   **높낮이 효과**:
    -   **고지대**: 높은 곳에 위치한 유닛은 낮은 곳의 적을 공격할 때 명중률과 데미지 보너스를 얻습니다.
    -   **사거리 제한**: 무기 사거리는 수직 높이까지 계산에 포함되어, 너무 높은 곳에 있는 적은 공격할 수 없습니다.
-   **시야 시스템**:
    -   **고지대 시야 보너스**: 높은 곳에 위치한 유닛은 더 넓은 범위의 적을 발견할 수 있습니다.
    -   **시야 범위**: 기본 시야 + (현재 높이 - 주변 평균 높이) 만큼 시야가 확장됩니다.
    -   **은신 및 차폐**: 숲, 건물 등의 장애물 뒤에 숨은 적은 시야에서 제외되거나 발견 확률이 감소합니다.
-   **밀치기 공격 시스템**:
    -   **밀치기 속성**: 일부 공격(돌진, 방패 밀기 등)은 대상을 1~2칸 밀어낼 수 있습니다.
    -   **낙하 데미지**: 밀려난 대상이 높은 곳에서 낮은 곳으로 떨어질 경우 낙차에 비례한 추가 데미지를 받습니다.
        -   낙차 1칸 = 경미한 데미지, 낙차 2칸+ = 심각한 데미지
        -   극심한 낙차(3칸+)의 경우 즉사 위험도 존재
    -   **전략적 활용**: 절벽 근처에서의 위치 선점이 중요한 전략 요소가 됩니다.
-   **지형 종류 및 효과**:
    -   **Plain(평지)**: 기본 지형, 특별한 효과 없음
    -   **Mountain(산)**: 이동 비용 +2, 고지대 보너스(공격력/명중률 +20%), 시야 범위 +2
    -   **Forest(숲)**: 이동 비용 +1, 은신 효과, 원거리 공격 회피율 +15%, 화염 속성 피해 +50%
    -   **Swamp(늪)**: 이동 비용 +3, 이동력 -1, 독 상태이상 확률 10%, 번개 속성 피해 +30%
    -   **Desert(사막)**: 이동 비용 +1, 갈증 상태(턴마다 MP -2), 화염 속성 저항 +20%, 얼음 속성 피해 +40%
    -   **Volcano(화산지대)**: 이동 비용 +2, 턴마다 화염 데미지, 화염 속성 피해 +100%, 화염 속성 저항 -50%
    -   **River(강)**: 이동 비용 +2, 젖은 상태(화염 저항 +30%, 번개 피해 +50%), 수영 불가 시 익사 위험
        - 번개 속성 공격 시 주변 1칸 범위 광역 피해 발생
    -   **Rocky(바위지대)**: 이동 비용 +1, 투사 무기 명중률 +10%, 낙석 위험 지역
    -   **Ice(빙하지대)**: 이동 비용 +1, 미끄러짐 효과(이동 후 추가 1칸 미끄러짐), 얼음 속성 저항 +50%, 화염 속성 피해 +30%
    -   **Cave(동굴)**: 이동 비용 +1, 시야 범위 -2, 음향 증폭(소음 기반 스킬 효과 +50%)
    -   **Bridge(다리)**: 이동 비용 0, 좁은 통로로 대형 유닛 통과 불가, 파괴 가능 구조물
    -   **Lava(용암)**: 진입 불가, 화염 속성 광역 데미지 방사(인접 칸에 화염 피해)
    -   **Quicksand(유사)**: 이동 비용 +4, 매 턴 침몰 진행(3턴 후 익사), 탈출 시 STR 체크 필요
    -   **Thorn(가시덤불)**: 이동 비용 +2, 진입 시 출혈 상태, 화염 속성으로 제거 가능
    -   **Mud(진흙)**: 이동 비용 +2, 기동성 -1, 번개 속성 전도율 증가(주변 2칸 광역 피해)

### 2.3. 환경 상호작용

#### 2.3.1. 날씨 시스템
-   **날씨 효과**:
    -   **맑음**: 기본 상태, 특별한 효과 없음
    -   **비**: 화염 속성 -30%, 번개 속성 +20%, 시야 범위 -1, 모든 유닛 젖은 상태
    -   **폭우**: 화염 속성 -50%, 번개 속성 +50%, 시야 범위 -2, 강 범람으로 일부 평지가 강으로 변환
    -   **눈**: 이동력 -1, 얼음 속성 +30%, 화염 속성 +20%, 발자국 추적 가능
    -   **블리자드**: 이동력 -2, 시야 범위 -3, 얼음 속성 +50%, 매 턴 동상 데미지
    -   **폭풍**: 원거리 공격 명중률 -20%, 비행 불가, 번개 속성 광역 피해 확률
    -   **사막 모래폭풍**: 시야 범위 -2, 화염 속성 +10%, 매 턴 질식 데미지, 기계 유닛 고장 확률
    -   **화산재**: 시야 범위 -1, 화염 속성 +20%, 매 턴 중독 데미지, 비행 고도 제한
    -   **안개**: 시야 범위 -3, 은신 효과 증가, 원거리 공격 명중률 -30%
    -   **오로라**: 마법 공격력 +20%, MP 회복률 +1, 환상 마법 저항 -20%
    -   **혹한**: 이동력 -1, 매 턴 HP -2, 화염 속성 회복 효과, 액체 지형 얼음화
    -   **열파**: 사막/화산 지형 피해 2배, 갈증 상태 확률, 얼음 지형 용해

#### 2.3.2. 지형-속성 상호작용
-   지형의 상태와 스킬의 속성이 결합하여 추가 효과를 발생시킵니다:
    -   **화염 속성 상호작용**:
        - 숲 + 화염 = 불타는 숲 (지속 화염 데미지, 연쇄 확산)
        - 가시덤불 + 화염 = 가시덤불 제거 (지형이 평지로 변화)
        - 얼음 + 화염 = 물웅덩이 생성 (임시 강 지형 효과)
        - 진흙 + 화염 = 건조한 땅 (이동 페널티 제거)
    -   **번개 속성 상호작용**:
        - 강/진흙 + 번개 = 주변 2칸 광역 감전 (체인 라이트닝)
        - 금속 장비 착용 시 번개 피해 +100%
        - 비 날씨 + 번개 = 전체 맵 번개 확률 증가
    -   **얼음 속성 상호작용**:
        - 강 + 얼음 = 임시 얼음 다리 생성 (3턴 후 해빙)
        - 진흙 + 얼음 = 빙판 (미끄러짐 거리 2배)
        - 화산 + 얼음 = 증기 폭발 (광역 데미지 + 시야 차단)
    -   **바람 속성 상호작용**:
        - 화염 + 바람 = 화염 확산 (인접 칸으로 번짐)
        - 독성 가스 + 바람 = 독성 확산
        - 모래폭풍 + 바람 = 모래폭풍 강화 (시야 완전 차단)
    -   **대지 속성 상호작용**:
        - 평지 + 대지 = 언덕 생성 (고지대 효과)
        - 동굴 + 대지 = 낙석 (광역 물리 데미지)
        - 절벽 + 대지 = 지진 (주변 유닛 넘어짐)
    -   **독 속성 상호작용**:
        - 늪지 + 독 = 독성 늪 (독 데미지 2배, 독 확산)
        - 강 + 독 = 독성 강물 (하류로 독 확산, 정화 시간 필요)
        - 바람 + 독 = 독성 바람 (광역 독 확산, 이동 경로 따라 중독)
        - 동굴 + 독 = 독가스 농축 (밀폐 공간에서 독 효과 3배)

#### 2.3.3. 특수 환경 지형
-   **추가 특수 지형**:
    -   **Altar(제단)**: 신성 속성 마법 위력 +50%, 언데드 유닛에게 지속 피해, MP 회복 +1
    -   **Graveyard(묘지)**: 언데드 소환 확률, 신성 속성 저항 +30%, 어둠 속성 강화 +20%
    -   **Crystal(수정지대)**: 마법 데미지 반사 30%, 마나 회복 +2, 물리 공격 시 수정 파편 피해
    -   **Teleporter(순간이동진)**: 맵 내 다른 순간이동진으로 즉시 이동, 1턴 쿨타임
    -   **Poison_Gas(독가스)**: 매 턴 독 데미지, 시야 범위 -1, 바람으로 확산/제거 가능
    -   **Web(거미줄)**: 이동 비용 +3, 탈출 시 STR 체크, 화염으로 제거 가능
    -   **Tar_Pit(타르 웅덩이)**: 이동 비용 +4, 화염 취약 +200%, 점착 상태(3턴간 이동력 -2)
    -   **Blessed_Ground(축복받은 땅)**: 아군 유닛 모든 능력치 +10%, 언데드/악마 진입 불가
    -   **Cursed_Ground(저주받은 땅)**: 매 턴 랜덤 디버프, 언데드 유닛 강화 +30%
    -   **Magnetic_Field(자기장)**: 금속 장비 착용 유닛 이동 제한, 번개 속성 집중

#### 2.3.4. 상태 이상 시스템
-   **기본 상태 이상**:
    -   **중독(Poison)**: 매 턴 HP 감소 (3-5턴 지속)
        - **약한 중독**: 매 턴 HP -3, 3턴 지속
        - **일반 중독**: 매 턴 HP -5, 4턴 지속  
        - **강한 중독**: 매 턴 HP -8, 5턴 지속
        - **치명적 중독**: 매 턴 HP -12, 5턴 지속 + 치료 효과 -50%
        - **독 데미지 공식**: `독 데미지 = 기본 독 데미지 × (1 - 독 저항률) × (1 + 독 취약성)`
        - **독 저항 계산**: `독 저항률 = (RES × 0.1) + 장비 독 저항 + 버프 효과`
    -   **화상(Burn)**: 매 턴 화염 데미지 (2-4턴 지속)
    -   **동상(Frostbite)**: 이동력 -1, 행동력 -1 (2-3턴 지속)
    -   **마비(Paralysis)**: 행동 불가 (1-2턴 지속)
    -   **수면(Sleep)**: 행동 불가, 공격받으면 즉시 해제
    -   **매혹(Charm)**: 1턴간 적으로 전환되어 아군 공격
    -   **침묵(Silence)**: 마법/스킬 사용 불가 (2-3턴 지속)
    -   **실명(Blind)**: 명중률 -50%, 시야 범위 -3 (2-4턴 지속)
    -   **출혈(Bleeding)**: 이동 시 추가 HP 감소 (3-5턴 지속)
-   **환경 상태 이상**:
    -   **젖은 상태(Wet)**: 화염 저항 +30%, 번개 피해 +50% (날씨/지형으로 발생)
    -   **갈증(Thirst)**: 매 턴 MP -2, 사막 지형에서 발생
    -   **질식(Suffocation)**: 매 턴 HP -3, 독가스/모래폭풍에서 발생
    -   **점착(Sticky)**: 이동력 -2, 타르/거미줄에서 발생 (3턴 지속)
    -   **발열(Fever)**: INT -20%, 화산/열파에서 발생 (5턴 지속)

-   **체력/마나 상태 효과**:
    -   **건강(Healthy)**: HP 80% 이상, 모든 행동 +10% 효율
    -   **부상(Injured)**: HP 50% 이하, 이동력 -1, 명중률 -10%
    -   **중상(Heavily Injured)**: HP 25% 이하, 모든 스탯 -20%, 절망 스킬 사용 가능
    -   **빈사(Near Death)**: HP 10% 이하, 행동력 -1, 크리티컬 확률 +25% (최후의 발악)
    -   **마나 충만(Mana Full)**: MP 90% 이상, 마법 스킬 위력 +20%, 쿨타임 -1턴
    -   **마나 부족(Low Mana)**: MP 30% 이하, 마법 스킬 위력 -15%, 실패 확률 10%
    -   **마나 고갈(Mana Depleted)**: MP 10% 이하, 마법 스킬 사용 불가, INT -30%

### 2.4. 캐릭터 시스템
-   **6대 주요 스탯**:
    -   **STR** (힘): 물리 공격력, 물리 스킬 위력
    -   **DEF** (방어): 물리 방어력, 최대 체력, 체력 관련 스킬 효과
    -   **DEX** (기술): 명중률, 회피율, 정밀 스킬 위력
    -   **AGI** (민첩): 행동 순서, 이동력, 기동성 스킬 효과
    -   **INT** (지능): 마법 공격력, 최대 MP, 지능형 스킬 위력
    -   **RES** (저항): 마법 방어력, 상태이상 저항, 정신력 스킬 효과
-   **개인별 성장률 시스템**: 
    -   각 캐릭터는 **고유한 스탯 성장률**을 가집니다 (예: Elena - STR 85%, INT 40%, Marcus - STR 60%, INT 90%)
    -   레벨업 시 각 스탯이 성장할 확률이 캐릭터마다 다르므로, 같은 클래스라도 최종 능력치가 크게 달라집니다
    -   이는 캐릭터의 **타고난 재능**을 나타내며, 어떤 방향으로 육성할지 결정하는 핵심 요소입니다

#### 2.4.1. 체력(HP) 계산 시스템
-   **기본 체력 공식**:
    ```
    최대 체력 = 20 (기본값) + (DEF × 4) + (레벨 × 2) + 장비 보정
    ```
    - **기본 체력**: 모든 캐릭터가 가지는 최소 체력 20
    - **DEF 보정**: 방어력 1당 체력 +4 (탱커 특성 강하게 반영)
    - **레벨 보정**: 레벨 1당 체력 +2 (성장에 따른 체력 증가)
    - **장비 보정**: 체력 증가 장비 및 액세서리 효과

-   **체력 성장 예시**:
    ```
    레벨 1 Elena (DEF 10): 20 + (10×4) + (1×2) = 62 HP
    레벨 5 Elena (DEF 14): 20 + (14×4) + (5×2) = 86 HP
    레벨 10 Elena (DEF 20): 20 + (20×4) + (10×2) = 120 HP
    레벨 15 Elena (DEF 25): 20 + (25×4) + (15×2) = 150 HP
    
    고 DEF 성장률 탱커 캐릭터 (레벨 15, DEF 35):
    20 + (35×4) + (15×2) = 190 HP (압도적 생존력)
    
    저 DEF 성장률 마법사 (레벨 15, DEF 15):
    20 + (15×4) + (15×2) = 110 HP (상대적으로 낮은 체력)
    
    ★ HP 차이: 80 HP (약 73% 차이) - DEF 투자의 가치 극대화
    ```

-   **체력 관련 장비 보정**:
    - **체력의 목걸이**: 최대 HP +20, HP 회복률 +1
    - **재생의 팔찌**: 매 턴 HP +3 자동 회복
    - **용비늘 갑옷**: 추가 HP 보정은 없지만 높은 방어력으로 간접 생존력 증가
    - **불멸자 갑옷**: 최대 HP +25, 죽음 시 1회 부활
    - **바바리안 갑옷**: 분노 상태 시 임시 HP +30

-   **체력 회복 시스템**:
    - **자연 회복**: 전투 종료 후 최대 HP의 10% 자동 회복
    - **휴식 회복**: 마을/캠프에서 완전 회복
    - **포션 회복**: 즉시 회복 (소형 25, 중형 50, 대형 100, 최고급 완전)
    - **마법 회복**: 힐 스킬로 즉시 회복
    - **장비 회복**: 재생 아이템으로 지속 회복

#### 2.4.2. 마나(MP) 계산 시스템
-   **기본 마나 공식**:
    ```
    최대 마나 = 10 (기본값) + INT + 레벨 + 장비 보정
    ```
    - **기본 마나**: 모든 캐릭터가 가지는 최소 마나 10
    - **INT 보정**: 지능력 1당 마나 +1 (마법사 특성 반영)
    - **레벨 보정**: 레벨 1당 마나 +1 (성장에 따른 마나 증가)
    - **장비 보정**: 마나 증가 장비 및 액세서리 효과

-   **마나 성장 예시**:
    ```
    레벨 1 Elena (INT 6): 10 + 6 + 1 = 17 MP
    레벨 5 Elena (INT 8): 10 + 8 + 5 = 23 MP
    레벨 10 Elena (INT 12): 10 + 12 + 10 = 32 MP
    레벨 15 Elena (INT 15): 10 + 15 + 15 = 40 MP
    
    고 INT 성장률 마법사 (레벨 15, INT 28):
    10 + 28 + 15 = 53 MP (높은 마법 지속력)
    
    저 INT 성장률 전사 (레벨 15, INT 8):
    10 + 8 + 15 = 33 MP (제한적 마법 사용)
    ```

-   **마나 관련 장비 보정**:
    - **마나의 목걸이**: 최대 MP +15, MP 회복률 +2
    - **마나 팔찌**: 매 턴 MP +2 자동 회복
    - **마법사 지팡이**: MP 소모 -20%, 추가 MP +10
    - **대마법사 지팡이**: MP 자동 회복 +2, 최대 MP +20
    - **마나 오브**: MP +20, 마법 회복 속도 +50%

-   **마나 회복 시스템**:
    - **자연 회복**: 매 턴 최대 MP의 5% 자동 회복
    - **휴식 회복**: 전투 종료 후 완전 회복
    - **포션 회복**: 즉시 회복 (소형 15, 중형 30, 대형 60, 최고급 완전)
    - **명상**: 행동 소모하여 MP 20% 즉시 회복
    - **장비 회복**: 마나 회복 아이템으로 지속 회복

### 2.5. 클래스 체인지 & 스킬 계승 시스템
-   **자유로운 클래스 변경**: 레벨과 간단한 조건만 만족하면 언제든 다른 클래스로 전직 가능
-   **스킬 완전 계승**: 
    -   **모든 배운 스킬을 영구 보존**: 클래스를 바꿔도 이전 클래스에서 익힌 모든 스킬을 계속 사용 가능
    -   **스탯 기반 스킬 위력**: 각 스킬은 특정 스탯에 의해 위력이 결정됩니다
        - 물리 스킬(검술, 창술) → STR 의존
        - 마법 스킬(파이어볼, 힐) → INT 의존  
        - 기교 스킬(암살, 정밀사격) → DEX 의존
        - 보조 스킬(가드, 도발) → DEF 의존
-   **전략적 육성의 예시**:
    -   **Elena**: STR 성장률 85%, INT 성장률 30%
        1. `Knight`로 시작 → STR 특화로 Slash 스킬이 1.35배 데미지 (85%/100 = 1.35)
        2. `Mage`로 전직 → 낮은 INT 성장률로 마법 스킬은 0.8배 데미지 (30%/100 = 0.8)
        3. `Paladin`으로 재전직 → 강력한 물리 공격 주력 + 보조 마법 조합, 물리가 압도적으로 강함
    -   **Marcus**: STR 성장률 45%, INT 성장률 90%  
        1. `Soldier`로 시작 → 기본 무기술은 약함 (STR 45% = 0.95배)
        2. `Mage`로 전직 → 높은 INT 성장률로 마법 스킬이 1.4배 데미지 (90%/100 = 1.4)
        3. `Spellsword`로 재전직 → 마법이 주력(1.4배), 검술은 보조용(0.95배)으로 명확한 차별화
-   **스킬 시너지 & 멀티클래스 전술**:
    -   **하이브리드 빌드**: 서로 다른 클래스의 스킬을 조합하여 독특한 전술 창조
        - `검사 + 마법사` → 화염 검기 콤보 (STR과 INT 모두 필요)
        - `도적 + 궁수` → 은신 저격수 (DEX 특화, 원거리 암살)
        - `성직자 + 기사` → 성기사 (DEF와 INT 균형, 탱힐러)
        - `마법사 + 궁수` → 마법 궁수 (INT와 DEX, 마법 화살)
    -   **성장률 기반 특화 전략**: 
        - **STR 고성장률 (80%+)**: 물리 스킬 1.3~1.4배 특화, 마법은 보조용
        - **INT 고성장률 (80%+)**: 마법 스킬 1.3~1.4배 특화, 물리는 MP 절약용
        - **DEX 고성장률 (80%+)**: 정밀 스킬 + 크리티컬 특화 전술가
        - **균형형 (모든 스탯 60% 내외)**: 모든 스킬을 1.1배 수준으로 안정적 활용
        - **극단 특화형**: 한 스탯 90%+ 성장률로 해당 타입만 1.4배+ 극대화
    -   **숙련도 시스템**: 
        - 스킬 사용 횟수에 따라 **숙련도**가 상승
        - 높은 숙련도 = 스킬 위력 보정, MP 소모 감소, 추가 효과 발동
        - 같은 스킬이라도 자주 사용한 캐릭터가 더 효과적으로 활용
        -   **스킬 합성 시스템** (Skill Fusion):
        - **기존 스킬 조합**: 보유한 2-3개 스킬을 **소모**하여 새로운 고유 스킬 창조
        - **합성 조건**: 특정 스킬 조합 + 최소 캐릭터 레벨만 만족하면 **100% 성공**
        - **창조적 조합**: 같은 재료 스킬이라도 캐릭터의 주력 스탯에 따라 다른 결과 생성
        - **희귀 스킬 획득**: 일반적인 클래스 체인지로는 얻을 수 없는 독특한 스킬들
        - **영구 소실**: 합성에 사용된 스킬들은 영구히 사라지므로 신중한 선택 필요
        - **합성 예시**:
            - `Slash(검격)` + `Fire_Magic(화염마법)` = `Flame_Sword(화염검)`
            - `Heal(치료)` + `Guard(방어)` = `Sanctuary(성역)` - 범위 힐+방어버프
            - `Stealth(은신)` + `Precise_Shot(정밀사격)` = `Assassinate(암살)` - 은신 상태에서 치명타 확정
            - `Lightning(번개)` + `Arrow(화살)` + `Wind(바람)` = `Storm_Arrow(폭풍화살)` - 3스킬 합성
        - **개인화된 결과**: 같은 조합이라도 시전자의 최고 스탯에 따라 위력/효과 달라짐
        - **장소별 특수 효과**:
            - **일반 장소**: 기본 스킬 생성
            - **마법사 탑**: 마법 계열 합성 시 MP 소모량 -20%, 사거리 +1
            - **대장간**: 물리 계열 합성 시 기본 위력 +15%, 관통 효과 추가
            - **신전/제단**: 회복/신성 계열 합성 시 범위 +1, 정화 효과 추가
            - **연금술소**: 상태이상 계열 합성 시 지속 시간 +50%, 추가 디버프 효과
            - **고대 유적**: 모든 합성 스킬에 희귀 특수 효과 추가 (크리티컬 확률 증가 등)
            - **용암 지대**: 화염 계열 합성 시 화상 확산 효과, 얼음 계열 합성 시 증기폭발 효과
            - **얼음 동굴**: 얼음 계열 합성 시 빙결 효과 강화, 화염 계열 합성 시 온도차 폭발
            - **폭풍우 중**: 번개 계열 합성 시 체인 라이트닝 효과, 바람 계열 합성 시 광역 확산

### 2.6. 전투 데미지 계산 시스템

#### 2.6.1. 고급 데미지 계산 공식
현재 게임에서는 단순한 스탯 차감 방식에서 벗어나 다층적 데미지 계산 시스템을 사용합니다:

-   **기본 데미지 공식**:
    ```
    물리 데미지 = (공격자 STR + 스킬 위력) - (방어자 DEF × 0.7)
    마법 데미지 = (공격자 INT + 스킬 위력) - (방어자 RES × 0.7)
    ```
    - 방어력에 0.7 배수 적용으로 과도한 방어 효과 방지
    - 최소 데미지 1 보장으로 완전 무효화 방지

-   **캐릭터별 성장률 기반 특화 시스템**:
    - 각 캐릭터의 고유한 스탯 성장률이 스킬 데미지에 직접 반영
    - **높은 성장률 = 특화 보너스**: STR 성장률 90% → 물리 스킬 1.4배 데미지
    - **보통 성장률 = 기본 수준**: STR 성장률 60% → 물리 스킬 1.1배 데미지  
    - **낮은 성장률 = 약화 페널티**: STR 성장률 30% → 물리 스킬 0.8배 데미지
    - 공식: `스킬 특화 보너스 = 0.5 + (해당 스탯 성장률 ÷ 100)`

-   **개선된 데미지 공식**:
    ```
    물리 데미지 = (STR × 1.5 + DEX × 0.5 + 스킬위력) × 성장률보너스 - DEF × 0.7
    마법 데미지 = (INT × 1.5 + RES × 0.5 + 스킬위력) × 성장률보너스 - RES × 0.7
    ```
    - 주력 스탯(STR/INT) 1.5배 + 보조 스탯(DEX/RES) 0.5배 계산
    - 캐릭터의 타고난 재능(성장률)이 스킬 위력에 큰 영향

-   **체력/마나 영향 시스템**:
    ```
    체력 기반 스킬 위력 = 기본 위력 × (현재 HP / 최대 HP) × DEF 보정
    마나 기반 스킬 위력 = 기본 위력 × (현재 MP / 최대 MP) × INT 보정
    ```
    - **체력 의존 스킬**: 방어, 도발, 버서커 스킬 등 (체력이 높을수록 효과 증가)
    - **마나 의존 스킬**: 모든 마법 스킬 (마나가 충분할수록 안정적 위력)
    - **위험 상태 보너스**: HP 25% 이하 시 절망 스킬 위력 +50%
    - **풀 마나 보너스**: MP 90% 이상 시 마법 스킬 위력 +20%

-   **클래스 스킬 보너스**:
    - 현재 클래스의 대표 스킬 사용 시 추가 10% 데미지 보너스
    - 예: Knight의 Slash, Mage의 Fireball

#### 2.6.2. 크리티컬 및 명중률 시스템
-   **크리티컬 확률 계산**:
    ```
    크리티컬 확률 = 5% + (공격자 DEX × 0.2%)
    크리티컬 데미지 = 기본 데미지 × 2.0
    ```
    - 높은 DEX 캐릭터일수록 크리티컬 빈도 증가
    - 크리티컬 발생 시 데미지 2배

-   **명중률 계산**:
    ```
    기본 명중률 = 85% + (공격자 DEX - 방어자 AGI) × 2%
    최종 명중률 = 기본 명중률 + 지형 보정 + 스킬 보정
    ```
    - DEX가 높으면 명중률 증가, AGI가 높으면 회피율 증가
    - 지형과 스킬 타입에 따른 추가 보정

#### 2.6.3. 지형 전투 보정
-   **고지대 보너스**:

### 2.7. 동적 전장 시뮬레이션

#### 2.7.1. 결계 시스템 (Battle Barrier)
-   **주인공의 고유 능력**: 전투 시작 시 주인공이 마법 결계를 생성하여 전투 구역을 제한합니다.
-   **MP 소비 메커니즘**:
    -   **기본 MP 소모**: 결계 유지를 위해 주인공의 최대 MP의 일정 비율을 소모
    -   **크기별 소모량**: 
        - 소형 결계 (15x15): 최대 MP의 10% 소모
        - 중형 결계 (21x21): 최대 MP의 20% 소모  
        - 대형 결계 (27x27): 최대 MP의 35% 소모
        - 거대 결계 (33x33): 최대 MP의 55% 소모
        - 광역 결계 (39x39): 최대 MP의 75% 소모
        - 초광역 결계 (45x45): 최대 MP의 90% 소모
-   **전투 참여 제한**: 
    -   결계 생성 시점에 **결계 안에 위치한 유닛들만** 전투에 참여 가능
    -   결계 밖의 유닛들은 전투에 개입할 수 없음 (시각적으로 반투명 처리)
    -   전투 중 결계를 벗어나려는 시도 시 보이지 않는 벽에 막힘

#### 2.7.2. 전략적 결계 선택
-   **작은 결계의 장점**: 
    -   MP 소모가 적어 주인공이 더 많은 스킬 사용 가능
    -   빠른 전투 종료로 외부 정보 신선도 유지
    -   **예시**: 정예 부대 10명 vs 적 정예 8명 → 신속한 기동전 (15x15 전장)
-   **큰 결계의 장점**:
    -   초대형 전장에서 군단 규모 부대 운용 가능
    -   복잡한 지형, 높이차, 환경 변화를 모두 활용한 전술
    -   대규모 스킬 합성, 환경 상호작용, 전략적 기지 건설 기회
    -   **예시**: 전체 군단 30명 vs 적군 40명 → 다층 방어선, 전술적 후퇴, 역습 등 군사 전략 (45x45 전장)

        - **기본 상황 (85% 확률)**: 평온한 승리 → 정상적인 휴식과 정비 가능
        - **외부 이벤트 발생 (15% 확률)**: 미리 설정된 외부 이벤트와 타이밍이 맞아떨어짐

#### 2.8.4. 제작 시스템 (Crafting)

##### 기본 재료
-   **광물**: 철광석, 미스릴, 오리하르콘 (무기/갑옷 제작)
-   **생물 소재**: 가죽, 비늘, 깃털, 뼈 (방어구/액세서리)
-   **마법 재료**: 마나석, 속성 수정, 룬스톤 (마법 장비)
-   **희귀 재료**: 용의 심장, 천사의 깃털, 악마의 뿔 (전설급 장비)

##### 제작 과정
1. **설계도 획득**: 상인 구입, 퀘스트 보상, 적 드롭
2. **재료 수집**: 전투 후 획득, 필드 채집, 몬스터 드롭
3. **제작 장소**: 대장간 (무기/갑옷), 마법 공방 (마법 장비), 연금술소 (포션)
4. **제작 비용**: 재료 + 골드 + 제작 시간
5. **품질 변동**: 제작자 스킬에 따라 일반/고급/최상급 품질 랜덤 결정

#### 2.8.5. 장비 효과의 데미지/방어 공식 반영

##### 무기 효과 적용
-   **기본 공격력 보정**:
    ```
    최종 공격력 = (기본 STR/INT + 무기 공격력) × 성장률 보너스 × 장비 보정
    장비 보정 = 1.0 + (무기 특수 효과) + (액세서리 보정)
    ```
    -   예시: 용검(+35 공격력, 화염 속성) + 힘의 반지(STR +3) 착용 시
    -   화염 속성 적용 시 추가 속성 데미지 계산

-   **속성 효과 계산**:
    ```
    속성 데미지 = 기본 데미지 × (1 + 속성 보너스) × (1 - 적 속성 저항)
    독 속성 데미지 = 독 기본 데미지 × (1 - 독 저항률) × 독 취약성 배수
    ```
    -   화염검: 기본 데미지 + 화염 속성 데미지
    -   번개검: 기본 데미지 + 체인 라이트닝 추가 피해
    -   독검/독침: 기본 데미지 + 즉시 독 데미지 + 지속 중독 상태

-   **특수 효과 발동**:
    -   **흡혈**: 최종 데미지의 30% HP 회복
    -   **관통**: 적 방어력의 일정 비율 무시
    -   **크리티컬 보정**: 장비 크리티컬 보너스 + DEX 보너스

##### 방어구 효과 적용
-   **물리 방어 공식**:
    ```
    받는 물리 데미지 = 적 공격력 - (DEF × 0.7 + 갑옷 방어력) × (1 + 방어구 보정)
    방어구 보정 = 방어력 무시 저항 + 크리티컬 저항 + 속성 저항
    ```

-   **마법 방어 공식**:
    ```
    받는 마법 데미지 = 적 마법력 - (RES × 0.7 + 마법 저항) × (1 + 마법 방어구 보정)
    ```

-   **상태이상 저항**:
    ```
    상태이상 저항률 = 기본 RES 저항 + 장비 상태이상 저항 + 액세서리 보정
    ```

##### 액세서리 통합 효과
-   **스탯 보정**:
    -   반지/목걸이의 스탯 증가가 데미지 공식에 직접 반영
    -   예: 힘의 반지(STR +3) → 물리 공격력 직접 증가

-   **확률 효과 중첩**:
    ```
    최종 크리티컬 확률 = 기본 DEX 크리티컬 + 무기 보너스 + 액세서리 보너스
    최종 회피율 = 기본 AGI 회피 + 갑옷 보너스 + 액세서리 보너스
    ```

-   **복합 효과 예시**:
    ```
    전투법사 Elena의 화염검 공격:
    
    기본 계산:
    - STR: 18 + 3(힘의 반지) = 21
    - 용검 공격력: +35 (화염 속성)
    - 성장률 보너스: STR 85% → ×1.35
    
    최종 데미지:
    기본 데미지 = (21 × 1.5 + 35) × 1.35 = 89
    화염 속성 추가 = 89 × 0.3 = 27 (화염 속성 30% 추가)
    
    적이 용비늘 갑옷(화염 저항 +30%) 착용 시:
    화염 데미지 감소 = 27 × 0.3 = 8
    최종 데미지 = 89 + (27 - 8) = 108
    ```
    
    ```
    암살자 Marcus의 독 단검 공격:
    
    기본 계산:
    - DEX: 16 + 2(민첩의 반지) = 18
    - 독 단검 공격력: +14 (독 속성)
    - 성장률 보너스: DEX 80% → ×1.3
    
    물리 데미지:
    기본 데미지 = (18 × 1.5 + 14) × 1.3 = 53
    
    독 속성 효과:
    즉시 독 데미지 = 8 × (1 - 적 독 저항 20%) = 6
    지속 중독 = 매 턴 5 데미지 × 4턴 (일반 중독)
    
    적이 중독 상태일 때 추가 독 공격 시:
    독 저항 감소 = 20% - 25% = -5% (독 취약)
    강화된 독 데미지 = 8 × (1 + 5%) = 8.4
    ```

#### 2.8.6. 장비 조합 전략
-   **물리 특화 빌드**: 고 STR 성장률 + 강력한 근접 무기 + 공격력 액세서리
-   **마법 특화 빌드**: 고 INT 성장률 + 속성 지팡이 + MP 효율 장비
-   **균형형 빌드**: 중간 성장률 + 하이브리드 무기 + 범용 방어구
-   **은신 특화 빌드**: 고 DEX 성장률 + 단검 계열 + 은신 강화 장비
-   **탱커 빌드**: 고 DEF 성장률 + 중갑 + 상태이상 저항 액세서리

이 시스템으로 **장비 선택의 전략적 깊이**와 **자원 관리의 중요성**을 동시에 제공하며, 캐릭터 육성과 더불어 **장비 최적화**도 중요한 게임플레이 요소가 됩니다.

### 2.9. 경험치, 골드, 보상 시스템

#### 2.9.1. 경험치 획득 시스템
-   **기본 경험치**:
    -   **적 처치**: 적 레벨 × 10 + 위험도 보너스
    -   **생존 보너스**: 전투 종료 시 생존한 아군 전체에게 기본 경험치의 50%
    -   **턴 효율 보너스**: 빠른 승리 시 추가 경험치 (25턴 이내 +20%, 20턴 이내 +35%, 15턴 이내 +50%)
    -   **목표 달성**: 특수 목표 완수 시 보너스 경험치 (예: 민간인 구출, 건물 파괴 등)

-   **행동별 경험치**:
    -   **공격 성공**: 5 경험치 (크리티컬 시 +3 보너스)
    -   **스킬 사용**: 스킬 MP 비용 × 2 경험치
    -   **아군 지원**: 힐, 버프 등 성공 시 8 경험치
    -   **전략적 행동**: 적 약점 공격, 지형 활용 시 추가 5 경험치

-   **경험치 분배 공식**:
    ```
    개인 경험치 = (기본 경험치 + 행동 경험치) × 레벨 차이 보정 × 클래스 보정
    레벨 차이 보정 = 1.0 + (적 평균 레벨 - 아군 레벨) × 0.1
    클래스 보정 = 0.9 (상급 클래스) / 1.0 (기본 클래스) / 1.1 (하급 클래스)
    ```

#### 2.9.2. 골드 획득 시스템
-   **전투 보상**:
    -   **적 처치 보상**: 적 레벨 × 8 + 장비 가치의 10%
    -   **완전 승리**: 모든 적 처치 시 +30% 골드 보너스
    -   **무손실 승리**: 아군 사망자 없을 시 +20% 골드 보너스
    -   **효율 보너스**: 짧은 턴 수 승리 시 골드 추가 (턴당 2% 감소, 최대 40% 보너스)

-   **필드 발견**:
    -   **보물상자**: 50~500 골드 (지역별 차등)
    -   **숨겨진 보물**: 100~1000 골드 (탐지 스킬 필요)
    -   **적 진영 수색**: 전투 후 적 캠프 수색으로 추가 골드

-   **특수 활동**:
    -   **용병 계약**: 마을/도시에서 의뢰 수행으로 골드 획득
    -   **상인 호위**: 상인 호송 성공 시 대량 골드 + 아이템 할인
    -   **귀중품 운반**: 고위험 고수익 운반 임무

#### 2.9.3. 아이템 획득 시스템
-   **적 드롭 아이템**:
    -   **장비 드롭**: 적이 착용한 장비 드롭 확률 15% (레어 적은 30%)
    -   **소모품 드롭**: 체력/마나 포션, 전투 아이템 드롭 확률 25%
    -   **재료 드롭**: 제작 재료, 인챈트 재료 드롭 확률 20%
    -   **희귀 아이템**: 보스급 적에게서만 드롭되는 전설급 아이템

-   **지역별 특산품**:
    -   **화산 지대**: 화염 속성 재료, 내열 장비 재료
    -   **빙하 지역**: 얼음 속성 재료, 방한 장비 재료  
    -   **고대 유적**: 마법 재료, 고대 문명 장비 설계도
    -   **마족 지역**: 어둠 속성 재료, 저주 장비 재료

-   **상인 거래**:
    -   **일반 상인**: 기본 아이템, 소모품 판매
    -   **전문 상인**: 특수 장비, 희귀 재료 판매 (높은 평판 필요)
    -   **떠돌이 상인**: 랜덤 희귀 아이템, 일회성 거래
    -   **암상인**: 불법 아이템, 저주 장비, 금지된 기술서

#### 2.9.4. 진급 및 보상 시스템
-   **계급 시스템**:
    -   **견습병** (레벨 1-5): 기본 급여 50골드/전투
    -   **정규병** (레벨 6-12): 기본 급여 80골드/전투 + 장비 지원
    -   **정예병** (레벨 13-20): 기본 급여 120골드/전투 + 특수 아이템 접근권
    -   **지휘관** (레벨 21+): 기본 급여 200골드/전투 + 전략 아이템 + 전술 스킬

-   **공적 시스템**:
    -   **영웅적 행위**: 특별한 전투에서의 활약으로 명성 상승
    -   **전략적 승리**: 불리한 상황에서의 역전승으로 특별 보상
    -   **민간인 구호**: 구출 임무 성공으로 도덕성 상승 + 특별 아이템
    -   **고난도 임무**: 위험한 임무 완수로 희귀 장비 및 스킬서 획득

## 3. 게임 플레이 방법

### 3.1. 기본 조작

#### 3.1.1. 턴 시작 및 전환
-   **턴 알림**: 턴이 바뀔 때마다 화면 중앙에 토스트 메시지로 **"아군 턴"** 또는 **"적군 턴"** 표시
-   **캐릭터 선택**: 자동 선택 없이 플레이어가 직접 아군 캐릭터를 클릭하여 선택
-   **이동 범위 표시**: 캐릭터 선택 시 자동으로 이동 가능 범위가 표시됩니다
    - **기본 이동력**: `DEX` 스탯에 기반한 기본 이동 거리
    - **지형 보정**: 지형별 이동 비용에 따라 실제 도달 가능 범위 계산
    - **시각적 표시**: 이동 가능한 타일은 녹색 하이라이트

#### 3.1.2. 행동 선택 UI
캐릭터 선택 시 머리 위에 행동 버튼들이 나타납니다:
-   **🗡️ 공격**: 일반 공격 모드로 전환 (1 액션 소모)
-   **✨ 스킬**: 스킬 선택 창을 열어 사용할 스킬 선택 (1+ 액션 소모)
-   **🎒 아이템**: 보유 아이템 목록에서 사용할 아이템 선택 (1 액션 소모)
-   **❌ 취소**: 캐릭터 선택 해제 및 행동 취소

#### 3.1.3. 행동 실행
-   **이동**: 녹색 이동 범위 내의 타일을 클릭하여 캐릭터 이동 (1 액션 소모)
-   **일반 공격**:
    1. '공격' 버튼 클릭
    2. **붉은색**으로 무기 사정거리에 따른 공격 가능 범위 표시
    3. 공격할 대상이 있는 타일 클릭하여 공격 실행 (1 액션 소모)
-   **스킬 사용**:
    1. '스킬' 버튼 클릭
    2. 스킬 선택 창에서 사용할 스킬 선택
    3. **붉은색**으로 해당 스킬의 사정거리 범위 표시
    4. 마우스 호버 시 **파란색**으로 광역 효과 범위 또는 정확한 타겟 타일 미리보기
    5. 대상 타일 클릭하여 스킬 발동 (1+ 액션 소모)
-   **아이템 사용**:
    1. '아이템' 버튼 클릭
    2. 보유 아이템 목록에서 사용할 아이템 선택
    3. 대상 지정이 필요한 경우 범위 표시 후 타일 클릭
    4. 아이템 효과 발동 (1 액션 소모)

#### 3.1.4. 액션 포인트 시스템
-   **기본 액션 포인트**: 모든 캐릭터는 턴마다 **2개의 액션 포인트** 보유
-   **DEX 보너스**: `DEX` 스탯에 따라 추가 액션 포인트 획득
    - DEX 15+ = +1 액션 포인트 (총 3개)
    - DEX 20+ = +2 액션 포인트 (총 4개)
-   **액션 종류 및 소모**:
    - **이동**: 1 액션 포인트 소모
    - **공격**: 1 액션 포인트 소모
    - **스킬**: 1 액션 포인트 소모 (스킬에 따라 더 많이 소모할 수도 있음)
    - **아이템 사용**: 1 액션 포인트 소모
-   **자유로운 조합**: 
    - 이동 2회 (2 액션)
    - 공격 2회 (2 액션)
    - 이동 + 공격 (2 액션)
    - 이동 + 스킬 (2 액션)
    - 스킬 + 아이템 (2 액션)
    - DEX 보너스 시: 이동 + 공격 + 공격 (3 액션) 등

#### 3.1.5. 턴 관리
-   **턴 종료**: 우측 상단의 **"턴 종료"** 버튼을 언제든 클릭 가능
    - 아직 행동하지 않은 아군이 있어도 강제로 턴 종료 가능
    - 개별 캐릭터가 액션 포인트를 다 쓰지 않아도 다른 캐릭터로 전환 가능
    - 팀 턴 종료 시 모든 아군의 행동 기회가 적군에게 넘어감

### 3.2. 카메라 조작
-   **이동**: `WASD` 또는 `화살표 키`로 카메라 이동
-   **줌 인/아웃**: `마우스 휠`로 확대/축소
-   **캐릭터 추적**: 선택된 캐릭터를 중심으로 카메라 자동 이동 (옵션)

### 3.3. UI 인터페이스 가이드

#### 3.3.1. 색상 코딩 시스템
-   **녹색**: 이동 가능 범위
-   **붉은색**: 공격/스킬 사정거리
-   **파란색**: 스킬 효과 범위 미리보기 (마우스 호버 시)
-   **노란색**: 선택된 캐릭터 하이라이트
-   **회색**: 행동 완료된 캐릭터

#### 3.3.2. 타일 범위 표시 시스템
-   **반투명 오버레이**: 모든 범위 표시는 지형 타일 상단 표면에 반투명으로 렌더링
-   **지형 고려**: 산, 숲, 늪 등 다양한 지형 지물 위에도 명확하게 구분되는 색상
-   **깊이 레이어링**: 
    - 1층: 기본 지형 타일 (불투명)
    - 2층: 지형 디테일 및 장애물 (불투명)
    - 3층: 범위 표시 오버레이 (반투명, 투명도 60%)
    - 4층: 캐릭터 및 오브젝트 (불투명)
-   **시각적 명확성**: 어두운 지형에서는 밝은 범위 색상, 밝은 지형에서는 진한 범위 색상 사용

#### 3.3.3. 타일 정보 시스템
-   **마우스 호버 감지**: 타일 위에 마우스 커서를 올려놓으면 즉시 반응
-   **정보 창 위치**: 왼쪽 하단에 타일 정보 패널 표시
-   **표시 정보**:
    - **지형 이름**: "평지", "산", "숲", "늪지" 등
    - **높이 정보**: "높이 2레벨" (고도 차이)
    - **이동 비용**: "이동 비용 +1" (해당 지형 진입 시)
    - **특수 효과**: "은신 효과", "화염 저항 +20%" 등
    - **환경 상태**: "젖은 상태", "불타는 중", "얼어붙음" 등
    - **점유 상태**: "아군 점유", "적군 점유", "중립" 등
-   **실시간 업데이트**: 전투 중 지형 변화 시 즉시 정보 갱신
-   **추가 세부사항**: 
    - 캐릭터가 위치한 타일: 캐릭터 이름, HP/MP, 상태이상 표시
    - 상호작용 가능한 오브젝트: "보물상자", "스위치", "함정" 등

#### 3.3.4. UI 요소 위치
-   **좌측 상단**: 현재 턴 정보 및 캐릭터 상태
-   **좌측 하단**: 마우스 호버 타일 정보 패널
-   **우측 상단**: 턴 종료 버튼
-   **캐릭터 위**: 행동 선택 버튼 (공격/스킬/아이템/취소)
-   **캐릭터 옆**: 남은 액션 포인트 표시 (예: ⚡2/3)
-   **화면 중앙**: 턴 전환 토스트 메시지
-   **하단 중앙**: 선택된 캐릭터의 상세 정보, 스킬 목록, 보유 아이템

### 3.4. 전략 팁

#### 3.4.1. 전투 기본 전략
-   **지형 활용**: 항상 적보다 높은 지형을 선점하여 전투를 유리하게 이끄세요.
-   **은신 전술**: 숲 지형을 활용하여 원거리 공격을 회피하거나 적의 시야 밖에서 기습하세요.
-   **속성 상성**: 적의 속성 저항력과 현재 지형 상태를 고려하여 가장 효과적인 스킬을 사용하세요.
-   **이동력 관리**: DEX 스탯과 지형을 고려하여 최적의 포지셔닝을 계획하세요.
-   **스킬 미리보기**: 스킬 사용 전 파란색 범위로 정확한 효과를 확인하세요.
-   **타일 정보 활용**: 마우스 호버로 지형 효과를 미리 확인하여 최적의 위치를 선택하세요.

#### 3.4.2. 액션 포인트 활용 전략
-   **기동전**: 이동 2회로 빠르게 포지션 변경 (측면 공격, 후퇴 등)
-   **화력 집중**: 공격 2회로 단일 대상 집중 공격
-   **혼합 전술**: 이동 + 공격으로 안전한 거리에서 타격 후 후퇴
-   **지원 역할**: 스킬 + 아이템으로 아군 버프 및 회복 집중
-   **DEX 특화**: 고 DEX 캐릭터는 3-4액션으로 연속 기동 및 공격
-   **자원 관리**: 모든 액션을 다 쓸 필요 없이 상황에 따라 보존
-   **캐릭터 육성 전략**:
    -   **성장률 우선**: 각 캐릭터의 **개인 성장률**을 파악하고 특화 방향을 결정하세요
    -   **스킬 수집**: 다양한 클래스를 경험하여 더 많은 스킬을 습득하세요
    -   **시너지 구축**: 보유한 스킬들 간의 조합을 고려한 전술을 개발하세요
    -   **장기 계획**: 최종 목표 빌드를 설정하고 역순으로 클래스 경로를 계획하세요
-   **실전 활용**: 
    -   높은 스탯에 의존하는 스킬을 주력으로, 낮은 스탯 스킬은 상황용으로 활용
    -   숙련도가 높은 스킬을 우선적으로 사용하여 효율성 극대화
    -   MP가 부족할 때는 물리 스킬로, MP가 충분할 때는 마법 스킬로 전환

### 4.2. 주요 클래스 설명

-   **`GameManager.gd` (싱글톤)**
    -   **역할**: 게임의 전체 상태(전투 중, 메뉴 등)와 턴 흐름을 관리하는 중앙 관리자.
    -   **주요 기능**: 전투 시작/종료 처리, `DEX` 기반 턴 순서 계산, 다음 턴으로 진행(`advance_turn`), 데미지 계산 로직 제공.
-   **`GameData.gd` (싱글톤)**
    -   **역할**: 게임의 모든 정적 데이터(클래스, 스킬, 지형 정보 등)를 보관하는 데이터베이스.
    -   **주요 기능**: 코드와 데이터를 분리하여 밸런스 조정이 용이하게 함. 환경 상호작용 규칙 정의.
-   **`BattleScene.gd`**
    -   **역할**: `BattleScene.tscn`에 대한 메인 스크립트로, 실제 전투의 모든 시각적 요소와 사용자 입력을 처리.
    -   **주요 기능**: 캐릭터 생성 및 배치, UI 업데이트(정보창, 버튼), 타일 클릭 및 캐릭터 행동에 대한 결과 처리, 카메라 제어.
-   **`BattleGrid.gd`**
    -   **역할**: 이소메트릭 맵 그리드의 생성과 관리를 담당.
    -   **주요 기능**: 맵 데이터 생성, 화면 좌표<->그리드 좌표 변환, 이동/공격 범위 계산 및 시각적 하이라이트 표시.
-   **`Character.gd`**
    -   **역할**: 게임 내 모든 유닛(아군/적군)의 데이터와 개별 행동을 정의하는 클래스.
    -   **주요 기능**: 스탯 관리, 레벨업 처리, 데미지 수신, 상태(이동 완료, 행동 완료 등) 추적.
-   **`WorldSimulator.gd` (싱글톤)**
    -   **역할**: 플레이어 전투와 병행하여 외부 전장의 상황 변화를 시뮬레이션하는 시스템.
    -   **주요 기능**: 외부 이벤트 타이밍 관리, 정보 신선도 계산, 전투 종료 후 결과 적용.
-   **`BattleBarrier.gd`**  
    -   **역할**: 주인공의 결계 능력을 관리하고 전투 영역을 제한하는 시스템.
    -   **주요 기능**: 결계 크기 선택 UI, MP 소모 계산, 참여 유닛 필터링, 결계 영역 시각화.
-   **`IntelligenceSystem.gd`**
    -   **역할**: 정찰로 획득한 정보의 품질과 유효성을 관리하는 시스템.
    -   **주요 기능**: 정보 수집, 시간 경과에 따른 신뢰도 감소, 정보 기반 전투 보정 계산.

## 5. 개발 규칙 및 가이드라인

### 5.1. GDScript 코딩 규칙
-   **명명 규칙**: 클래스는 `PascalCase`, 변수/함수/신호는 `snake_case`, 상수는 `SCREAMING_SNAKE_CASE`.
-   **타입 힌트**: 모든 변수, 함수 매개변수, 반환값에 타입 힌트를 의무적으로 사용.
-   **주석**: 복잡한 함수 상단에는 목적, 매개변수, 반환값에 대한 설명을 명시. `##` 사용.
-   **오류 처리**: `assert`와 `push_error`를 적절히 사용하고, 조기 반환(early return) 패턴으로 코드 가독성 확보.

### 5.2. 아키텍처 규칙
-   **싱글톤**: `GameManager`, `GameData` 등 전역 상태를 관리하는 용도로만 제한적으로 사용.
-   **신호(Signal)**: 다른 노드 트리나 계층 간의 통신(느슨한 결합)을 위해 사용. (예: `BattleGrid`의 타일 클릭 -> `BattleScene`에서 처리)
-   **의존성**: 하드코딩된 경로(`get_node("/root/...")`) 사용을 금지하고, `@onready`나 의존성 주입을 통해 참조.

### 5.3. 다국어 지원 시스템 (i18n)
-   **번역 시스템 아키텍처**: 
    -   **LocalizationManager.gd** (싱글톤): 전역 언어 설정 및 번역 관리
    -   **TranslationService.gd**: Gemma 3 LLM과의 통신 및 번역 캐시 관리
    -   **CSVTranslationLoader.gd**: CSV 파일 기반 번역 데이터 로드/저장
-   **데이터 구조**:

-   **AI 번역 통합**:
    -   **Gemma 3 API 연동**: 게임 컨텍스트를 포함한 전문 번역
    -   **배치 번역**: 새로운 텍스트를 자동으로 모든 언어로 번역

-   **실시간 언어 변경**: 게임 중에도 언어를 즉시 전환 가능
-   **폰트 시스템**: 언어별 최적화된 폰트 자동 로드 (한글, 일본어, 중국어 등)

## 7. 이소메트릭 타일 시스템 현황

### 7.1. 현재 구현된 기능
-   **마름모꼴 타일 렌더링**: 70x35 픽셀 크기의 완벽한 이소메트릭 다이아몬드 형태
-   **3D 깊이감 표현**: 높이차에 따른 자동 측면 생성 및 음영 처리
-   **좌표 변환 시스템**: 정사각형 그리드 ↔ 이소메트릭 마름모 자동 변환
-   **지형별 색상 구분**: 15가지 지형 타입별 고유 색상 지원
-   **높이 기반 시각화**: 높이에 따른 밝기 조정 및 접근 불가 지역 표시

### 7.2. 기술적 세부사항
-   **타일 크기**: 70x35 픽셀 (이소메트릭 2:1 비율)
-   **좌표 변환 공식**:
    ```
    iso_x = (grid_x - grid_y) * 35
    iso_y = (grid_x + grid_y) * 17.5
    ```
-   **높이 표현**: 각 높이 레벨당 15픽셀 Y 오프셋
-   **측면 렌더링**: 인접 타일과의 높이차 계산하여 자동 생성

### 7.3. 향후 개선 계획
#### 7.3.1. 스프라이트 기반 렌더링 (우선순위: 높음)
현재 Polygon2D 단색 표현을 텍스처 기반으로 업그레이드:
-   **지형별 픽셀 아트 스프라이트 제작**:
    -   평지: 잔디 텍스처 (64x32 PNG)
    -   산: 바위 텍스처 + 눈 덮인 봉우리
    -   숲: 나무 실루엣 + 잎사귀 디테일
    -   늪: 물기 있는 진흙 + 기포 효과
    -   사막: 모래 언덕 + 선인장
    -   화산: 용암 흐름 + 연기 파티클
    -   강: 물 흐름 애니메이션 + 반사 효과
-   **높이별 변형 스프라이트**: 같은 지형도 높이에 따라 다른 변형 제공
-   **계절별/날씨별 변형**: 눈 덮인 버전, 비 젖은 버전 등

#### 7.3.2. 애니메이션 효과 (우선순위: 중간)
-   **지형 애니메이션**:
    -   강: 물결 효과
    -   화산: 용암 글로우 + 파티클
    -   불타는 땅: 화염 효과
    -   얼음: 반짝임 효과
-   **환경 파티클**:
    -   눈/비 날씨: 파티클 시스템
    -   안개: 반투명 오버레이
    -   모래폭풍: 움직이는 모래 텍스처

#### 7.3.3. 고급 시각 효과 (우선순위: 낮음)
-   **동적 조명**: 화염, 마법 등의 광원 효과
-   **그림자 시스템**: 높이에 따른 실시간 그림자
-   **시차 스크롤링**: 배경 레이어 추가

### 7.4. 현재 지형 표현력 평가
**✅ 충분히 표현 가능한 요소들:**
-   기본 지형 구분 (평지, 산, 숲, 물 등)
-   높이 차이 및 고저차 표현
-   지형 간 경계 및 전환
-   시각적 깊이감 및 3D 효과
-   마우스 인터랙션 (호버, 클릭)

**🔄 개선이 필요한 요소들:**
-   지형 디테일 (현재는 단색, 향후 텍스처 필요)
-   특수 효과 (화염, 물 흐름 등의 애니메이션)
-   날씨/시간대 변화 표현

**결론**: 현재 시스템은 이소메트릭 SRPG의 핵심 요구사항을 모두 만족하며, 스프라이트 교체만으로도 상업적 품질의 비주얼을 달성할 수 있습니다.

```gdscript
# scripts/MapManager.gd (신규 생성)
extends Node
class_name MapManager

signal map_saved(map_path: String)
signal map_loaded(map_data: Dictionary)

const SYSTEM_MAPS_DIR = "res://maps/system_stages/"

# 현재 랜덤 생성된 맵을 JSON 파일로 저장
func save_current_map(battle_grid: BattleGrid, metadata: Dictionary) -> String:
    var map_data = {}
    
    # 메타데이터 설정
    map_data["metadata"] = {

    }
    
    # 지형 데이터 추출
    map_data["terrain_data"] = extract_terrain_data(battle_grid)
    
    # 승리/패배 조건 (기본값)
    map_data["victory_conditions"] = [
        {"type": "eliminate_all_enemies", "required": true}
    ]
    map_data["defeat_conditions"] = [
        {"type": "all_players_defeated", "required": true}
    ]
    
    # 환경 설정
    map_data["environment"] = {
        "weather": "Clear",
        "time_of_day": "Day",
        "special_effects": [],
        "music_theme": "default_battle"
    }
    
    # 파일로 저장
    var file_path = CUSTOM_MAPS_DIR + map_data["metadata"]["stage_id"] + ".json"
    var file = FileAccess.open(file_path, FileAccess.WRITE)
    if file:
        file.store_string(JSON.stringify(map_data, "\t"))
        file.close()
        emit_signal("map_saved", file_path)
        print("맵이 저장되었습니다: ", file_path)
        return file_path
    else:
        push_error("맵 저장 실패: " + file_path)
        return ""

# BattleGrid에서 지형 정보 추출
func extract_terrain_data(battle_grid: BattleGrid) -> Dictionary:
    var terrain_data = {
        "width": battle_grid.GRID_WIDTH,
        "height": battle_grid.GRID_HEIGHT,
        "default_height": 0,
        "tiles": []
    }
    
    for x in range(battle_grid.GRID_WIDTH):
        for y in range(battle_grid.GRID_HEIGHT):
            if battle_grid.terrain_grid.has(Vector2i(x, y)):
                var tile = battle_grid.terrain_grid[Vector2i(x, y)]
                terrain_data["tiles"].append({
                    "x": x,
                    "y": y,
                    "type": tile["type"],
                    "height": tile["height"],
                    "state": tile.get("state", "Normal")
                })
    
    return terrain_data

# 저장된 맵 불러오기
func load_map(file_path: String) -> Dictionary:
    var file = FileAccess.open(file_path, FileAccess.READ)
    if file:
        var json_string = file.get_as_text()
        file.close()
        
        var json = JSON.new()
        var parse_result = json.parse(json_string)
        if parse_result == OK:
            var map_data = json.data
            emit_signal("map_loaded", map_data)
            return map_data
        else:
            push_error("JSON 파싱 오류: " + str(parse_result))
    else:
        push_error("맵 파일 로드 실패: " + file_path)
    
    return {}

# 저장된 맵을 BattleGrid에 적용
func apply_map_to_battle_grid(map_data: Dictionary, battle_grid: BattleGrid):
    battle_grid.clear_terrain()
    
    var terrain_data = map_data["terrain_data"]
    battle_grid.GRID_WIDTH = terrain_data["width"]
    battle_grid.GRID_HEIGHT = terrain_data["height"]
    
    # 타일 정보 복원
    for tile_data in terrain_data["tiles"]:
        var pos = Vector2i(tile_data["x"], tile_data["y"])
        battle_grid.terrain_grid[pos] = {
            "type": tile_data["type"],
            "height": tile_data["height"],
            "state": tile_data.get("state", "Normal")
        }
    
    # 비주얼 업데이트
    battle_grid.generate_terrain_visual()
    print("맵이 성공적으로 로드되었습니다: ", map_data["metadata"]["name"])

func generate_stage_id() -> String:
    return "custom_" + str(Time.get_unix_time_from_system())

# 사용 가능한 맵 목록 반환
func get_available_maps() -> Array:
    var maps = []
    
    # 커스텀 맵들
    var dir = DirAccess.open(CUSTOM_MAPS_DIR)
    if dir:
        dir.list_dir_begin()
        var file_name = dir.get_next()
        while file_name != "":
            if file_name.ends_with(".json"):
                var map_data = load_map(CUSTOM_MAPS_DIR + file_name)
                if map_data.has("metadata"):
                    maps.append({
                        "path": CUSTOM_MAPS_DIR + file_name,
                        "metadata": map_data["metadata"],
                        "type": "custom"
                    })
            file_name = dir.get_next()
    
    return maps
```

```gdscript
    var file = FileAccess.open(file_path, FileAccess.READ)
    if file:
        var json_string = file.get_as_text()
        file.close()
        
        var json = JSON.new()
        var parse_result = json.parse(json_string)
        if parse_result == OK:
            current_scenario = json.data
            current_chapter_index = 0
            emit_signal("scenario_loaded", current_scenario)
            return current_scenario
        else:
            push_error("시나리오 JSON 파싱 오류: " + str(parse_result))
    else:
        push_error("시나리오 파일 로드 실패: " + file_path)
    
    return {}

func load_chapter_map(chapter_index: int) -> Dictionary:
    if not current_scenario.has("chapters") or chapter_index >= current_scenario["chapters"].size():
        push_error("유효하지 않은 챕터 인덱스: " + str(chapter_index))
        return {}
    
    var chapter = current_scenario["chapters"][chapter_index]
    var map_data = {}
    
    match chapter["map_type"]:
        "file":
            # 저장된 맵 파일에서 로드
            var map_manager = MapManager.new()
            map_data = map_manager.load_map(chapter["map_reference"])
        "random":
            # 랜덤 생성 파라미터를 사용해서 맵 생성
            map_data = generate_random_map_from_params(chapter["map_reference"])
        "builtin":
            # 내장된 시스템 맵 로드
            map_data = load_builtin_map(chapter["map_reference"])
        _:
            push_error("알 수 없는 맵 타입: " + chapter["map_type"])
    
    return map_data
```

```gdscript
func validate_map(map_data: Dictionary) -> Dictionary:
    var validation_result = {
        "is_valid": true,
        "warnings": [],
        "errors": []
    }
    
    var terrain_data = map_data["terrain_data"]
    
    # 기본 검증
    if terrain_data["tiles"].size() < 10:
        validation_result["errors"].append("맵이 너무 작습니다 (최소 10타일 필요)")
        validation_result["is_valid"] = false
    
    # 스폰 지역 검증
    var metadata = map_data["metadata"]
    if metadata.has("player_spawn_area") and metadata.has("enemy_spawn_area"):
        var player_area = metadata["player_spawn_area"]
        var enemy_area = metadata["enemy_spawn_area"]
        
        # 스폰 지역이 겹치는지 확인
        if areas_overlap(player_area, enemy_area):
            validation_result["warnings"].append("플레이어와 적 스폰 지역이 겹칩니다")
    
    # 접근 가능성 검증 (모든 타일이 연결되어 있는지)
    if not is_map_connected(terrain_data):
        validation_result["warnings"].append("일부 지역이 고립되어 있습니다")
    
    return validation_result

func areas_overlap(area1: Dictionary, area2: Dictionary) -> bool:
    return not (area1.x + area1.width <= area2.x or 
                area2.x + area2.width <= area1.x or
                area1.y + area1.height <= area2.y or
                area2.y + area2.height <= area1.y)

func is_map_connected(terrain_data: Dictionary) -> bool:
    # 간단한 연결성 검사 (BFS 활용)
    if terrain_data["tiles"].size() == 0:
        return false
    
    var visited = {}
    var queue = [terrain_data["tiles"][0]]
    visited[Vector2i(queue[0]["x"], queue[0]["y"])] = true
    
    while queue.size() > 0:
        var current = queue.pop_front()
        var current_pos = Vector2i(current["x"], current["y"])
        
        # 인접 타일 확인
        for direction in [Vector2i(0, 1), Vector2i(1, 0), Vector2i(0, -1), Vector2i(-1, 0)]:
            var neighbor_pos = current_pos + direction
            if not visited.has(neighbor_pos):
                var neighbor_tile = find_tile_at(terrain_data["tiles"], neighbor_pos)
                if neighbor_tile and is_passable_terrain(neighbor_tile["type"]):
                    visited[neighbor_pos] = true
                    queue.append(neighbor_tile)
    
    # 방문한 타일 수와 전체 이동 가능한 타일 수 비교
    var passable_count = 0
    for tile in terrain_data["tiles"]:
        if is_passable_terrain(tile["type"]):
            passable_count += 1
    
    return visited.size() >= passable_count * 0.8  # 80% 이상 연결되면 OK

func find_tile_at(tiles: Array, pos: Vector2i) -> Dictionary:
    for tile in tiles:
        if tile["x"] == pos.x and tile["y"] == pos.y:
            return tile
    return {}

func is_passable_terrain(terrain_type: String) -> bool:
    return terrain_type != "Lava" and terrain_type != "Deep_Water"
```

```gdscript
    return "player_" + str(OS.get_unique_id())
```

## 9. 시나리오 시퀀스 및 인터미션 시스템

### 9.1. 시스템 개요

전투 맵과 전투 맵 사이에 진행되는 **스토리 시퀀스**와 **인터미션 시스템**을 구성하여 플레이어에게 몰입감 있는 스토리 경험과 캐릭터 관리 기회를 제공합니다.

#### 9.1.1. 게임 플로우 구조
```
메인 메뉴 → 시나리오 선택 → [반복: 스토리 시퀀스 → 캐릭터 배치 → 전투 → 결과 처리 → 인터미션] → 엔딩
```

#### 9.1.2. 시퀀스 타입 분류
- **Pre-Battle Sequence**: 전투 전 스토리 (배경 설명, 작전 브리핑)
- **Post-Battle Sequence**: 전투 후 스토리 (결과 처리, 캐릭터 반응)
- **Intermission Sequence**: 중간 관리 (캐릭터 육성, 상점, 대화)

```gdscript
        change_state(GameFlowState.STORY_SEQUENCE)
        execute_pre_battle_sequence()

func execute_story_events(events: Array, callback: Callable):
    # 스토리 이벤트들을 순차적으로 실행
    var event_queue = events.duplicate()
    _execute_next_story_event(event_queue, callback)

func _execute_next_story_event(event_queue: Array, callback: Callable):
    if event_queue.is_empty():
        callback.call()
        return
    
    var event = event_queue.pop_front()
    
    match event["type"]:
        "dialogue":
            dialogue_system.dialogue_finished.connect(_execute_next_story_event.bind(event_queue, callback), CONNECT_ONE_SHOT)
            dialogue_system.start_dialogue(event)
        "character_join":
            GameData.add_character_to_party(event["character_id"])
            _execute_next_story_event(event_queue, callback)
        "item_obtain":
            GameData.add_item(event["item_id"], event["quantity"])
            _execute_next_story_event(event_queue, callback)

func change_state(new_state: GameFlowState):
    current_state = new_state
    emit_signal("game_flow_state_changed", GameFlowState.keys()[new_state])
    print("게임 플로우 상태 변경: ", GameFlowState.keys()[new_state])
```

### 9.7. 개발 워크플로우 및 시스템 장점

#### 9.7.1. 단순화된 개발 과정

```
1. 스토리 에디터에서 대화 시퀀스 제작 (복잡한 분기 없이 직선형)
2. 시나리오 매니저에서 챕터에 연결
3. 맵 에디터에서 제작한 맵과 연동
4. 게임에서 바로 테스트 가능
```

#### 9.7.2. 시스템의 장점

**개발자 관점:**
- ✅ **간단한 구조**: 복잡한 분기나 조건 없이 직관적인 시스템
- ✅ **빠른 제작**: 대화 + 이벤트만으로 스토리 완성
- ✅ **쉬운 테스트**: 복잡한 시나리오 없이 바로 확인 가능
- ✅ **유지보수 용이**: 단순한 데이터 구조로 버그 최소화

**플레이어 경험:**
- ✅ **깔끔한 진행**: 복잡하지 않은 UI로 스토리에 집중
- ✅ **직관적 조작**: 캐릭터 선택과 배치가 간단명료
- ✅ **빠른 게임 진행**: 불필요한 선택지나 복잡한 메뉴 없음
- ✅ **안정적 경험**: 단순한 시스템으로 오류 발생 최소화

### 9.8. 완전한 통합 시스템 구성

#### 9.8.1. 전체 개발 워크플로우

```
맵 에디터 시스템 ← → 시나리오 시스템
        ↓                    ↓
1. 랜덤 맵 생성           1. 스토리 에디터에서 대화 생성

        ↓                    ↓
        통합된 게임 경험
```

#### 9.8.2. 핵심 개선 사항 정리

**제거된 복잡한 기능들**
- ❌ 선택지 시스템 (분기 스토리 없음)
- ❌ 음성 지원 (텍스트 기반)
- ❌ 복잡한 시퀀스 조합 (기본 시퀀스만)
- ❌ 8명 배치 제한 (유연한 인원 선택)
- ❌ 실시간 전력 평가 (단순 확인만)

**남겨진 핵심 기능들**
- ✅ 기본 대화 시스템 (화자 + 텍스트 + 초상화)
- ✅ 간단한 컷신 (카메라 이동, 캐릭터 이동)
- ✅ 인터미션 관리 (캐릭터, 상점, 저장, 진행)
- ✅ 캐릭터 배치 (선택 → 배치 → 제거)
- ✅ 스토리 에디터 (대화 + 이벤트 편집)

## 🎯 **완성된 통합 시스템의 강점**

### **개발 효율성**
1. **빠른 프로토타이핑**: 랜덤 맵 생성 + 즉시 저장으로 아이디어 구현 속도 향상
2. **직관적인 에디터**: 복잡한 기능 없이 필수 기능만으로 학습 곡선 최소화
3. **모듈화된 시스템**: 맵/스토리/캐릭터 시스템이 독립적으로 작동하여 병렬 개발 가능

### **콘텐츠 제작 편의성**
1. **재사용 가능한 자산**: 저장된 맵과 스토리 시퀀스를 다른 챕터에서 재활용
2. **실시간 테스트**: 에디터에서 바로 플레이 테스트 가능

### **플레이어 경험**

2. **선택의 자유**: 캐릭터 배치와 인터미션에서 플레이어의 선택권 보장
3. **몰입도 유지**: 복잡한 UI 없이 게임 내용에 집중

이제 **핵심 기능에 집중한 실용적인 시나리오 시스템**으로 효율적이고 안정적인 게임 개발이 가능합니다! 🎮✨

### 10.2. 전투 로그 수집 시스템

#### 10.2.1. 상세 전투 로그 매니저

```gdscript

const ANALYTICS_DIR = "user://battle_analytics/"

            "aggressive_moves": 0,

func log_player_action(action_data: Dictionary):
    var detailed_action = {

        "action_type": action_data["type"],

func analyze_action_pattern(action: Dictionary):
    # 스킬 사용 패턴 분석
    if action["skill_used"] != "":
        if not current_battle_log["skill_usage"].has(action["skill_used"]):
            current_battle_log["skill_usage"][action["skill_used"]] = 0
        current_battle_log["skill_usage"][action["skill_used"]] += 1
    
    # 이동 패턴 분석
    if action["action_type"] == "move":
        analyze_movement_pattern(action)
    
    # 공격 패턴 분석
    if action["action_type"] == "attack":
        analyze_attack_pattern(action)
    
    # 지형 활용 분석
    analyze_terrain_usage(action)

func analyze_movement_pattern(action: Dictionary):
    var movement_data = {
        "turn": action["turn"],
        "from": action["position_before"],
        "to": action["position_after"],
        "distance": action["position_before"].distance_to(action["position_after"]),
        "direction": get_movement_direction(action["position_before"], action["position_after"]),
        "tactical_intent": determine_tactical_intent(action)
    }
    
    current_battle_log["movement_patterns"].append(movement_data)
    
    # 전술적 성향 분석
    match movement_data["tactical_intent"]:
        "aggressive":
            current_battle_log["positioning_analysis"]["aggressive_moves"] += 1
        "defensive":
            current_battle_log["positioning_analysis"]["defensive_moves"] += 1
        "flanking":
            current_battle_log["positioning_analysis"]["flanking_attempts"] += 1
        "retreat":
            current_battle_log["positioning_analysis"]["retreat_count"] += 1

func analyze_attack_pattern(action: Dictionary):
    # 선호 사거리 분석
    var attack_range = action["distance_to_target"]
    if attack_range <= 1:
        increment_preference("close_range")
    elif attack_range <= 3:
        increment_preference("medium_range")
    else:
        increment_preference("long_range")
    
    # 높이 우위 활용도
    if action["height_advantage"]:
        increment_preference("height_advantage")
    
    # 엄폐물 활용도
    if action["cover_utilized"]:
        increment_preference("cover_usage")

func analyze_terrain_usage(action: Dictionary):
    var terrain_interaction = {
        "turn": action["turn"],
        "action_type": action["action_type"],
        "terrain_type": action["terrain_to"],
        "strategic_value": calculate_terrain_strategic_value(action)
    }
    
    current_battle_log["terrain_interactions"].append(terrain_interaction)
    
    # 지형 선호도 분석
    if not terrain_usage_patterns.has(action["terrain_to"]):
        terrain_usage_patterns[action["terrain_to"]] = {
            "usage_count": 0,
            "effectiveness": 0.0,
            "contexts": []
        }
    
    terrain_usage_patterns[action["terrain_to"]]["usage_count"] += 1
    terrain_usage_patterns[action["terrain_to"]]["contexts"].append(action["action_type"])

func determine_tactical_intent(action: Dictionary) -> String:
    var enemy_positions = get_enemy_positions()
    var player_pos = action["position_after"]
    
    # 적에게 가까워졌는지 확인
    var closest_enemy_before = get_closest_enemy_distance(action["position_before"])
    var closest_enemy_after = get_closest_enemy_distance(action["position_after"])
    
    if closest_enemy_after < closest_enemy_before:
        # 적 주변으로 우회하는지 확인
        if is_flanking_move(action["position_before"], action["position_after"], enemy_positions):
            return "flanking"
        else:
            return "aggressive"
    elif closest_enemy_after > closest_enemy_before:
        return "retreat"
    else:
        return "defensive"

func is_flanking_move(from: Vector2i, to: Vector2i, enemy_positions: Array) -> bool:
    # 측면 공격 시도인지 판단하는 로직
    for enemy_pos in enemy_positions:
        var angle_before = get_angle_to_enemy(from, enemy_pos)
        var angle_after = get_angle_to_enemy(to, enemy_pos)
        var angle_diff = abs(angle_after - angle_before)
        
        # 90도 이상 각도 변화가 있으면 측면 공격으로 판단
        if angle_diff > PI/2:
            return true
    
    return false

func calculate_terrain_strategic_value(action: Dictionary) -> float:
    var value = 0.0
    var terrain = action["terrain_to"]
    
    # 지형별 전략적 가치 계산
    match terrain:
        "Hill", "Mountain":
            value += 0.8  # 높이 우위
        "Forest":
            value += 0.6  # 엄폐 효과
        "Water":
            value += 0.3  # 이동 제한
        "Plains":
            value += 0.4  # 이동성
        "Ruins":
            value += 0.7  # 방어 보너스
    
    # 상황에 따른 가치 조정
    if action["height_advantage"]:
        value += 0.2
    if action["cover_utilized"]:
        value += 0.2
    
    return min(value, 1.0)

func finalize_battle_log(victory: bool):
    current_battle_log["battle_end_time"] = Time.get_datetime_string_from_system()
    current_battle_log["victory"] = victory
    current_battle_log["turn_count"] = GameManager.current_turn
    
    # 최종 패턴 분석
    analyze_overall_patterns()
    
    # 로그 저장
    save_battle_log()
    
    # LLM 분석 요청
    request_llm_analysis()

func analyze_overall_patterns():
    # 선호 사거리 결정
    var range_preferences = count_range_preferences()
    current_battle_log["tactical_preferences"]["preferred_range"] = get_dominant_preference(range_preferences)
    
    # 스킬 우선순위 정렬
    var skill_list = []
    for skill_id in current_battle_log["skill_usage"]:
        skill_list.append({"skill": skill_id, "count": current_battle_log["skill_usage"][skill_id]})
    skill_list.sort_custom(func(a, b): return a["count"] > b["count"])
    
    current_battle_log["tactical_preferences"]["skill_priority"] = skill_list.slice(0, 5)  # 상위 5개
    
    # 지형 선호도 계산
    var terrain_preferences = []
    for terrain in terrain_usage_patterns:
        var usage_data = terrain_usage_patterns[terrain]
        terrain_preferences.append({
            "terrain": terrain,
            "usage_count": usage_data["usage_count"],
            "effectiveness": usage_data["effectiveness"]
        })
    terrain_preferences.sort_custom(func(a, b): return a["usage_count"] > b["usage_count"])
    
    current_battle_log["tactical_preferences"]["terrain_preference"] = terrain_preferences.slice(0, 3)
    
    # 위험 감수 성향 분석
    var aggressive_ratio = float(current_battle_log["positioning_analysis"]["aggressive_moves"]) / max(1, current_battle_log["turn_count"])
    if aggressive_ratio > 0.6:
        current_battle_log["tactical_preferences"]["risk_tolerance"] = "high"
    elif aggressive_ratio < 0.3:
        current_battle_log["tactical_preferences"]["risk_tolerance"] = "low"
    else:
        current_battle_log["tactical_preferences"]["risk_tolerance"] = "medium"

func save_battle_log():
    var timestamp = Time.get_datetime_string_from_system().replace(":", "-").replace(" ", "_")
    var filename = ANALYTICS_DIR + "battle_" + current_battle_log["stage_id"] + "_" + timestamp + ".json"
    
    var file = FileAccess.open(filename, FileAccess.WRITE)
    if file:
        file.store_string(JSON.stringify(current_battle_log, "\t"))
        file.close()
        print("전투 로그 저장 완료: ", filename)
    else:
        push_error("전투 로그 저장 실패: " + filename)

func generate_session_id() -> String:
    return "session_" + str(Time.get_unix_time_from_system()) + "_" + str(randi() % 10000)

func get_player_identifier() -> String:
    # 실제로는 Steam ID나 고유 식별자 사용
    return "player_" + str(OS.get_unique_id())
```

- 플레이어가 같은 전략만 반복 사용할 경우 카운터 전략 도입

**3. 플레이어 성장 분석**

- 학습 곡선에 맞는 콘텐츠 제공

**4. 콘텐츠 최적화**

- 게임 밸런스 조정을 위한 데이터 수집

## 11. 요괴 기반 적 시스템 

### 11.1. 시스템 개요

게임은 18세기 일본의 요괴 도감 『화도백귀야행』을 기반으로 한 독창적인 적 시스템을 구현했습니다. 총 18종의 전통 요괴들이 각각의 원래 설화와 특성을 게임 시스템에 맞게 재해석되어 등장합니다.

### 11.2. 구현 현황

#### 11.2.1. 핵심 파일 구조
```
scripts/
├── EnemyData.gd          # 기본 요괴 8종 + 시스템 구조
├── EnemyDataExtended.gd  # 추가 요괴 10종 + 확장 기능  
├── EnemySkills.gd        # 20+ 요괴 전용 스킬
└── EnemyManager.gd       # 적 관리 및 전투 통합
```

#### 11.2.2. 요괴 분류 체계
- **정령계**: 목매, 야마비코, 야마와라와, 야마우바 (자연 특화)
- **동물계**: 네코마타, 갓파, 다누키, 가와우소, 조로구모 (기동성 특화)
- **쓰쿠모가미**: 고토후루누시, 비와보쿠보쿠, 고소데노테, 지리즈카카이오 (특수 능력)
- **자연계**: 텐구, 기쓰네비, 쓰루베비 (환경 조작)
- **언데드계**: 소겐비 (원념 기반)
- **악마계**: 오니 (압도적 화력)

### 11.3. 전략적 특징

#### 11.3.1. 지형 특화 시스템
각 요괴은 특정 지형에서 강화된 능력을 발휘:
- **숲**: 목매의 나무 융합, 치유 능력 증폭
- **강/늪**: 갓파의 물 공격, 끌어당기기 특화
- **산**: 텐구의 비행, 바람 조작 능력
- **동굴**: 조로구모의 거미줄 덫, 독 확산
- **화산**: 오니의 지옥 화염, 압도적 위력

#### 11.3.2. 속성 상호작용
요괴들 간 협력으로 강력한 복합 효과 생성:
- **화염 + 바람**: 기쓰네비 + 텐구 = 화염 확산
- **번개 + 물**: 갓파 물 지형 + 번개 공격 = 체인 라이트닝
- **독 + 바람**: 조로구모 독 + 바람 = 독성 확산

#### 11.3.3. 특수 이벤트 전투
테마별 요괴 조합으로 특별한 전투 경험:
- **쓰쿠모가미 모임**: 고토후루누시, 비와보쿠보쾌, 지리즈카카이오의 음악 협연
- **산의 정령들**: 야마비코, 야마우바, 텐구의 산악 제압전
- **여우불 행렬**: 기쓰네비 + 다누키의 환상 기만전

## 12. 조선-일본 역사 기반 클래스 시스템

### 12.1. 시스템 개요

게임은 역사적 진정성을 바탕으로 한 조선시대와 일본의 무관, 무력 집단을 클래스로 재현했습니다. 각 클래스는 실제 역사적 배경과 특성을 게임 시스템에 맞게 재해석하여 구현되었습니다.

### 12.2. 조선시대 클래스 체계

#### 12.2.1. 삼수병 체계 (임진왜란 후 훈련도감 중심)
조선시대 최고의 정예 부대로 각각 특화된 전투 스타일을 보유:
- **포수 (砲手)**: 조총 화력 특화, 원거리 제압 전문
- **살수 (殺手)**: 창술 및 근접 전투 특화, 방어 진형 전문  
- **궁수 (弓手)**: 활 연사 특화, 은신 및 기동 전문

#### 12.2.2. 특수 정예 클래스
- **착호갑사 (捉虎甲士)**: 추적, 덫 설치, 암살 전문
- **기병 (騎兵)**: 기동력과 돌격 전문, 기마 전술 특화
- **수군 (水軍)**: 해상 전투 및 함포 사격 전문

### 12.3. 일본 클래스 체계

#### 12.3.1. 사무라이 계급
- **다이묘 (大名)**: 최고 지휘관, 전략 및 지휘 특화
- **하타모토 (旗本)**: 쇼군 직속 무사, 정예 전사
- **고케닌 (御家人)**: 일반 무사, 균형 잡힌 전투 능력

#### 12.3.2. 특수 무력 집단
- **닌자 (忍者)**: 은신, 암살, 정보 수집 전문
- **야마부시 (山伏)**: 산악 전투 및 자연 마법 특화
- **소헤이 (僧兵)**: 승려 전사, 치유 및 근접 전투 병행
- **아시가루 (足軽)**: 보병, 집단 전술 특화

#### 12.3.3. 종교 및 민간 클래스
- **미코 (巫女)**: 신토 무녀, 정화 및 예언 마법
- **이타코 (イタコ)**: 영매, 저주 및 소령 마법
- **기도사 (祈祷師)**: 불교 승려, 치유 및 축복 마법

### 12.4. 전략적 특징

#### 12.4.1. 삼수병 연계 시스템
세 클래스 간 조합으로 강력한 시너지 효과:
- **포수 + 살수**: 화력 지원 후 돌격 연계
- **포수 + 궁수**: 원거리 화력 집중 포격
- **살수 + 궁수**: 근거리 견제 후 원거리 마무리
- **삼수 완편**: 모든 상황에 대응 가능한 완벽한 조합

#### 12.4.2. 특수 합동 공격 "삼수일체"
포수, 살수, 궁수가 모두 참여하는 강력한 합동 공격:
- **5x5 범위 복합 피해**: 화약 폭발 + 창격 + 화살 연사
- **시전 조건**: 세 클래스가 모두 전장에 있고 특정 거리 내 위치
- **쿨타임**: 전투당 1회 제한

### 12.5. 역사적 진정성

#### 12.5.1. 조선시대 원전 기반
- **삼수병**: 임진왜란 후 훈련도감의 실제 군사 개편
- **착호갑사**: 호환 퇴치를 위한 전문 부대

- **닌자**: 이가류, 고가류 등 실제 닌자 유파
- **야마부시**: 슈겐도 수행자의 산악 전투 기술

### 12.6. 게임 밸런스

#### 12.6.1. 클래스 간 상성
- **포수 vs 기병**: 기병 돌격 전 저격으로 제압
- **살수 vs 닌자**: 창술 리치로 은신 접근 차단

- **산악**: 야마부시, 착호갑사 유리

## 13. 조선시대 삼수병 클래스 및 스킬 시스템

### 13.1. 삼수병 체계 개요

임진왜란 이후 조선의 군사 개편으로 탄생한 훈련도감 중심의 삼수병 체계를 완전히 재현했습니다. 각 클래스는 15-16개의 고유 스킬을 보유하며, 역사적 전투 기법을 게임 메커니즘으로 구현했습니다.

### 13.2. 포수 (砲手) 클래스

#### 13.2.1. 핵심 특성
- **조총 화력**: 강력한 원거리 공격력
- **재장전 시스템**: 턴별 장전 관리 필요
- **연계 사격**: 다른 포수와 협력 공격

#### 13.2.2. 주요 스킬 (15개)
- **정조준**: 명중률 +50%, 크리티컬 확률 +30%
- **삼단 철환**: 관통 공격으로 일직선상 적 3명 동시 타격
- **별화포**: 화약 폭발로 3x3 범위 광역 공격
- **연사 장전**: 1턴에 2발 연속 사격 가능
- **진압 사격**: 적 이동력 -2, 행동력 -1 디버프

### 13.3. 살수 (殺手) 클래스

#### 13.3.1. 핵심 특성
- **창술 특화**: 리치 2 근접 공격
- **방어 진형**: 팀 전체 방어력 향상
- **백병전 마스터**: 근접 전투 최강

#### 13.3.2. 주요 스킬 (16개)
- **일자 창격**: 직선 2칸 관통 공격
- **팽배 방어**: 주변 아군 방어력 +30%
- **낭선비검**: 검과 창 이도류 연속 공격
- **진격 돌파**: 돌진하며 경로상 모든 적 공격
- **방진 구축**: 3x3 범위 요새화 (방어력 +50%)

### 13.4. 궁수 (弓手) 클래스

#### 13.4.1. 핵심 특성
- **연사 속도**: 턴당 여러 발 사격
- **특수 화살**: 다양한 속성 화살 보유
- **은신 기술**: 숨어서 기습 공격

#### 13.4.2. 주요 스킬 (16개)
- **속사**: 1턴에 3발 연속 사격
- **편전**: 소형 화살로 빠른 견제 공격
- **신기전**: 로켓 화살로 원거리 폭발 공격
- **만석궁**: 최대 사거리에서 관통 공격
- **곡사**: 장애물 너머 포물선 공격

### 13.5. 특수 정예 클래스

#### 13.5.1. 착호갑사 (捉虎甲士) - 16개 스킬
- **맹호격**: 호랑이 사냥 기법을 응용한 강력한 일격
- **함정 설치**: 적 이동 경로에 덫 설치
- **산군의 포효**: 적 전체에 공포 효과

#### 13.5.2. 기병 (騎兵) - 16개 스킬
- **기마 돌격**: 원거리에서 돌진하며 강화된 공격
- **치고 빠지기**: 공격 후 즉시 후퇴
- **철기병 돌파**: 적 진형을 관통하며 광역 공격

#### 13.5.3. 수군 (水軍) - 16개 스킬
- **천자총통 포격**: 화포를 이용한 장거리 공격
- **학익진**: 포위 진형으로 적 퇴로 차단
- **화공**: 화선을 이용한 적 함선 공격

### 13.6. 삼수병 연계 시스템

#### 13.6.1. 조합 보너스
- **포수 + 살수**: 화력 지원 보너스 (+20% 공격력)
- **포수 + 궁수**: 원거리 집중 포격 (+30% 사거리)
- **살수 + 궁수**: 근거리 견제 보너스 (+25% 회피율)
- **삼수 완편**: 모든 능력치 +15%, 특수 스킬 해금

#### 13.6.2. 특수 합동 공격 "삼수일체"
- **시전 조건**: 포수, 살수, 궁수가 모두 5칸 이내 위치
- **효과**: 5x5 범위에 복합 피해 (화약 + 창격 + 화살)
- **피해량**: 각 클래스 공격력의 150% 합산
- **쿨타임**: 전투당 1회, 3턴 준비 시간 필요

### 13.7. 역사적 배경

#### 13.7.1. 임진왜란 교훈
- 조총의 위력을 목격한 조선이 화기 도입 결정
- 창술의 전통을 유지하며 근접 전투 보완
- 활쏘기의 장점을 살린 원거리 견제 유지

#### 13.7.2. 훈련도감 체계
- 유성룡의 군사 개편안을 바탕으로 한 체계적 훈련
- 세 병과의 상호 보완적 전투 운용
- 실전 경험을 바탕으로 한 전술 개발

### 13.8. 게임 밸런스

- **포수**: 화력은 강하지만 재장전 필요
